# 设计报告交付目录

本目录是仓库根目录内受版本控制的正式报告副本；根目录布局收口后，Markdown、HTML 和证据索引均以此处为准。

| 文件 | 用途 |
|---|---|
| [设计报告.md](设计报告.md) | 可编辑的报告正文源文件。 |
| [设计报告.html](设计报告.html) | 独立排版的交付预览；当前没有自动导出器，提交前须与 Markdown 手工同步并运行漂移检查。 |

## 数据引用纪律

- 报告中的量化结论应能回链到 [../docs/验收证据索引.md](../docs/验收证据索引.md)；
- 运行/测量原始文件保留在 `../tool-of-rei/evidence/` 的外部归档，不直接复制入报告目录；
- 当前 20 例完整 P4 审计绑定 BIN `d819641d…`，F0 两位小数显示构建绑定不同 BIN `e30d16c4…`；报表不得把它们写成同一构建，除非在最终提交上重新完成统一审计。

## 排版与同步

- 报告正文严格限制为 A4 纸 8 页以内，首页中文摘要不超过 300 字。
- HTML 是独立排版的派生预览。同步修改 Markdown 与 HTML 后，运行 `python scripts/check_report_sync.py --update` 写入正文 SHA-256，再运行不带参数的命令检查漂移。
