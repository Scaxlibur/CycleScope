# DG4202 谐波功能信号前端—FPGA 全链路测试计划

> 计划编号：M12
> 版本：v0.2
> 日期：2026-07-31
> 状态：历史 M12 执行计划。真实 DG4202→FPGA→LAN→P4 的 60 个工程观测点已完成并通过；本文保留原计划、工具缺口与用例定义，当前结论以 [测试与证据索引](../测试与证据索引.md) 为准。
> 测试链：DG4202 → AD8065 → AD9226 → FPGA FIR/抽取 → LAN采集电脑

## 1. 目的与适用范围

上一套以单音、任意波和前端分层测量为主的测试已由用户确认通过。本计划不重复做基础
硬件资格审查，而是使用 **DG4202 内置谐波发生器**，验证下列能力：

1. DG4202 设置的基波及1～2条谐波能否经模拟前端、ADC和FPGA被正确恢复；
2. 基波不是最大谱线、最小谱线为5 mVpeak、高达H16时，算法是否仍能找到真正基频；
3. 各谱线幅值、总波形Vpp和真RMS是否满足题目5 mV误差限值；
4. 相同绝对频率由不同谐波阶次生成时，端到端测量结果是否一致；
5. 以同一谐波发生器生成`u_b + u_J`时，FPGA能否抑制1 MHz以上干扰而保留`u_b`；
6. 能否为比赛自带的这台DG4202生成“设置值→FPGA码值”的专用逐点校准表。

原计划只验收至 FPGA 输出及电脑离线恢复；后续 M12 已完成到 ESP32-P4 的工程联调。本文的“后续”“待执行”和 WaveBench 接口建议均是历史计划语义，不能反向否定 M12 已归档结论。

## 2. 本轮明确不再检查的项目

根据用户授权，以下项目已经退出本轮门禁，测试时直接使用读数：

- 不检查AD8065反馈取样位于50 Ω串联电阻之前还是之后；
- RTM2032 CH1/CH2探头倍率及菜单倍率均按1×处理，不做探头交换或修正；
- 不检查内部正负电源轨和器件温度。

因此：

- CH1直接作为放大器输入节点读数`Vin`；
- CH2直接作为AD9226输入节点读数`Vadc`；
- 不再插入第三个运放输出诊断点，也不计算`Gfb/Kmatch`；
- DG设置值是比赛误差基准，CH1/CH2只用于观察、保护和分层判责。

上述豁免不取消输出过幅、ADC OTR、削顶、自激和数据链错误的停机门槛。

## 3. 题目形成的正式边界

依据[赛题原文](https://github.com/Scaxlibur/CycleScope/blob/main/docs/G题_周期信号测量分析装置/full.md)和
[主办方答疑](https://github.com/Scaxlibur/CycleScope/blob/main/docs/主办方答疑/26电赛问题解答2607292103.txt)：

| 项目 | 正式要求 |
|---|---:|
| `u_a`总峰峰值 | 100～250 mVpp |
| `u_a`全部谱线 | 10～200 kHz |
| `u_b`总峰峰值 | 50～250 mVpp |
| `u_b`全部谱线 | 10～500 kHz |
| 波形组成 | 基波＋1条或2条谐波 |
| 单条谱线最小幅值 | 5 mVpeak |
| 基波强弱 | 不保证是最大谱线 |
| 干扰`u_J` | 200 mVpp单音，`f_J ≥ 1 MHz` |
| Vpp、真RMS、谱线峰值误差 | 绝对值不大于5 mV |
| 基频误差 | 绝对值不大于1 kHz |
| FFT频率分辨率 | 不大于500 Hz |
| 评分幅值基准 | 原则上以工作正常的信号发生器设置值为准 |

DG4202的谐波幅度SCPI单位为Vpp，而题目频谱幅值是正弦峰值，因此必须显式换算：

```text
Uset_peak(n) = DG_harmonic_amplitude_vpp(n) / 2
```

不允许把DG的单条谱线Vpp、合成波形Vpp和频谱单边峰值混成一个字段。

### 3.1 理论值、信号源回显和真实输出必须分开

根据当前实物使用事实，不能从DG4202内部取得每条谐波的**真实模拟输出幅度**。即使某个
SCPI查询或profile返回幅度，它也至多是配置值回显，不是独立测量结果。因此本计划冻结
如下参考层级：

| 层级 | 数值来源 | 含义 |
|---|---|---|
| 理论设置层 | 本地manifest按DG写入参数计算 | 比赛参考值和校准目标 |
| 输入实测层 | RTM CH1原始波形在本地做FFT | 放大器BNC端实际到达的各谱线 |
| ADC节点实测层 | RTM CH2原始波形在本地做FFT | AD9226输入端实际各谱线 |
| FPGA码域层 | FPGA输出码序列在本地做FFT | ADC/FIR/抽取后实际读取结果 |

正式测试不依赖DG返回逐条谐波幅度。理论值必须由本地manifest重新计算；示波器层必须从
导出的原始波形统一做FFT，不能拿屏幕上的自动谐波表代替；FPGA层必须从保存的原始码序列
重算。三类数据缺少任意一类，该点都不能进入校准表。

## 4. DG4202与WaveBench能力核查结论

### 4.1 DG4202硬件能力

当时使用的本地外部资料 `tools/wavebench/doc/instruments/DG4000_ProgrammingGuide_CN.md` 记录：

- `HARMonic:ORDEr`最高为16，同时受“最大输出频率÷基波频率”限制；
- H2～H16均可分别设置Vpp幅度和0°～360°相位；
- 类型支持`EVEN / ODD / ALL / USER`；
- `USER`使用`X`加15位掩码，依次控制H2～H16；
- 例如`X001000000000001`表示基波＋H4＋H16。

所以“最高16次谐波”是 **DG4202信号发生器** 的能力，不是RTM2032示波器的波形输出
能力。

### 4.2 当前WaveBench实际能力

核查`tools/wavebench`当前v0.8.22源码、配置和运行时解析结果：

| 能力 | 当前状态 |
|---|---|
| `rigol.dg4202`解析到外置插件 | 已解析到`wavebench-rigol-dg4000 1.1.0` |
| H2～H16配置profile/query模型 | 驱动具备；只作配置审计，不作为真实输出幅度来源 |
| 安全切换`EVEN / ODD / ALL` | 支持，但公开受控窗口仅H2～H5 |
| 任意设置H2～H16逐条幅度/相位 | **当前公共接口不支持** |
| 写入`USER`自定义掩码 | **当前公共接口不支持** |
| harmonic CLI子命令 | **当前没有** |
| `source.harmonic_configure` run-plan步骤 | **当前没有** |
| 失败后完整谐波profile恢复 | 驱动内部已有并经过既有低阶测试 |

现有`SourceHarmonicConfiguration`只携带`order + preset`，不能表达每条谱线的幅度、相位
和USER选择。驱动内部恢复代码虽然会写H2～H16，但那是失败恢复专用私有路径，不能被
本计划直接调用来冒充正式配置接口。任何可用的幅度query也只能证明“仪器接受/回显了
什么设置”，不能证明BNC端实际输出了同样幅度。

**结论：DG4202硬件具备完整能力；当前WaveBench只能自动完成低阶预设测试，尚不能
全自动执行本计划的任意H2～H16矩阵。** 为避免手工配置，正式live campaign开始前应先
完成第5节的最小公开接口补齐。

## 5. 全自动执行的最小WaveBench前置能力

本节是接口需求，不表示本计划已经修改WaveBench代码。

### 5.1 建议的新run-plan步骤

```toml
[[steps]]
kind = "source.harmonic_configure"
channel = 1
fundamental_frequency_hz = 40000
fundamental_amplitude_vpp = 0.080
offset_v = 0.0
order = 5
preset = "USER"
user_mask = "X010100000000000" # H3 + H5

[[steps.components]]
order = 3
amplitude_vpp = 0.060
phase_deg = 270

[[steps.components]]
order = 5
amplitude_vpp = 0.040
phase_deg = 300
```

配置与输出开关必须是两个独立步骤；`harmonic_configure`不得隐式打开输出。

### 5.2 配置事务必须具备的保护

1. 打开同一个持久source session，完整快照通道状态和H2～H16 profile；
2. 强制输出OFF并回读确认；
3. 设置HARM模式、基频、基波Vpp、0 V offset、各活动谱线幅度/相位、阶数和USER掩码；
4. 对仪器实际支持的字段逐项回读；幅度/相位回显只记为配置证据，不记为测量值；
5. 校验每条绝对频率`f_n = n × f_0`不超过仪器限制；
6. 计算活动分量保守上界，要求：

```text
Vsum_pp = V1_pp + Σ Vn_pp ≤ 0.45 Vpp
```

7. 以高密度离线合成再次计算实际Vpp、峰值和crest factor；
8. 任何失败都先输出OFF，再恢复完整profile及所有可回读字段；恢复结果不明确时锁止后续写入；
9. runner不得发送裸SCPI，也不得调用下划线开头的私有恢复函数；
10. run artifact必须保存写前、目标、写后和最终恢复四份profile。

### 5.3 自动化接口验收顺序

```text
模型/plan schema离线测试
→ FakeTransport逐命令回读与失败恢复测试
→ run check（零仪器I/O）
→ 只读IDN/profile
→ 输出保持OFF的单组H2～H5配置回读
→ 低幅实物闭环
→ 才允许M12正式矩阵
```

USER、H6～H16或逐阶幅相任一能力未通过上述门禁时，不允许用面板手工设置后把结果标成
“全自动M12通过”。

## 6. 正式接线、读数与安全门槛

```text
DG4202 CH1（50 Ω显示语义、0 V offset、HARM）
    │
    ├── RTM2032 CH1：高阻、1×，直接读取Vin
    │
    └── 装置BNC → AD8065同相放大器
                       │
                       └── 输出串联匹配 → AD9226通道A输入
                                                └── RTM2032 CH2：高阻、1×，直接读取Vadc

AD9226 A → FPGA 65 MSPS → 三级FIR → /16 → 4.0625 MS/s → 8192点帧 → LAN电脑
```

硬门槛：

- 所有活动分量Vpp之和不超过`0.45 Vpp`；
- CH1直接读数正常目标不超过`0.55 Vpp`；
- CH2直接读数正常目标不超过`2.35 Vpp`；
- CH2超过`2.5 Vpp`、出现削顶、自激或ADC OTR时立即DG OFF；
- CRC、包序号、frame_id、FIFO overflow或frame drop任一异常时保存证据并停止该批次；
- 改变基频、谱线、相位或幅度前必须先输出OFF；
- 最终恢复为`SIN / 100 kHz / 50 mVpp / 50 Ω / 0 V / OFF`并回读。

## 7. 数学模型和manifest口径

每个用例只根据**本地准备写入DG的设置值**生成理论波形，不从DG查询值反推理论值：

```text
u(t) = Σ U_n,peak × sin(2πn f0 t + φ_n)

f_n = n × f0
U_n,peak = Vpp_n / 2
Urms = sqrt(Σ U_n,peak² / 2)       # 无DC且严格正交
Upp = max(u) - min(u)              # 用高密度数值波形计算
```

对每条活动谱线`n`，本地统一分析程序必须生成以下对应关系：

```text
Utheory_n = 本地manifest中的设置峰值
Uch1_n    = RTM CH1原始波形FFT得到的单边峰值
Uch2_n    = RTM CH2原始波形FFT得到的单边峰值
Acode_n   = FPGA码序列FFT得到的单边峰值，单位code peak

Ksrc_n    = Uch1_n / Utheory_n
Gfront_n  = Uch2_n / Uch1_n
Kcode_n   = Acode_n / Uch2_n
Ke2e_n    = Acode_n / Utheory_n
Cjudge_n  = Utheory_n / Acode_n
```

这里的`Acode_n`必须注明样点阶段。当前正式LAN帧若是FIR和抽取之后的数据，就写成
`sample_stage = post_fir_decimation`，不能冒充裸AD9226输出码。500 kHz以内有效谱线可
直接建立上述映射；1 MHz以上干扰在FPGA层应被抑制，只计算`CH2 → FPGA`衰减，不要求
FPGA码域幅度复现理论干扰值。

若FPGA另有可验证的FIR前原始ADC捕获，则额外保存：

```text
Aadc_raw_n = FIR前AD9226码序列FFT峰值
Kadc_raw_n = Aadc_raw_n / Uch2_n
Hdigital_n = Acode_n / Aadc_raw_n
```

这样可以把ADC量化与FIR/抽取分开；若没有这条原始路径，`Kcode_n`只能代表
“ADC＋FIR＋抽取”的组合比例，报告中不得声称已经单独标定裸ADC。

CH1和CH2必须来自同一次RTM acquisition，并由同一套本地FFT实现处理。理论层、RTM层
和FPGA层使用相同的单边峰值定义、频率搜索规则与窗函数增益口径；不比较未同步采集之间
的绝对相位。

每份manifest至少包含：

```text
case_id
DG4202 IDN与序列号
source channel/load/mode/offset
f0、order、preset、user_mask
H1～H16：active/frequency/Vpp/peak/phase
理论值事实源：local_set_manifest
DG query字段及“仅为设置回显”标志
理论整体Vpp、真RMS、crest factor
活动分量Vpp之和
采样率、FIR哈希、抽取率、FFT长度和窗函数
calibration_id
预期FPGA折叠频率及验收门槛
manifest SHA-256
```

FPGA输出频点间隔为：

```text
4,062,500 / 8192 = 495.91064453125 Hz
```

测试频率优先取500 Hz整数倍，但不能因其与FFT栅格不完全重合而只读最近一个bin。幅值
必须使用正弦拟合、局部频率搜索或经过相干增益修正的窗函数估计。

## 8. 每个测试点的自动闭环

1. 从本地manifest生成理论波形、各谱线峰值、Vpp、RMS和安全上界；
2. 读取DG可用的通道/harmonic配置字段和RTM双通道状态；
3. DG OFF下事务式写入；可回读字段逐项核对，但不把回显当实际幅度；
4. 显式DG ON，等待至少1 s；
5. RTM单次acquisition同时保存CH1和CH2原始波形；
6. 保存至少32个与DG ON时间窗相交的完整FPGA帧，正式边界和干扰点至少64帧；
7. DG OFF并回读输出状态；
8. 用同一分析程序分别对CH1、CH2和FPGA码序列做FFT，生成逐谱线四层对应表；
9. 保存理论manifest、RTM/FPGA原始数据、FFT结果、命令日志、pcap、profile和SHA-256；
10. 单点PASS后才能进入下一点，FAIL不自动提高幅度重试。

批量任务每50点生成一次checkpoint；中断后只能从最后一个完整且哈希通过的点续跑，不能
跳过失败点继续拼成一份“全部通过”的报告。

## 9. H1：H2～H16逐阶选择与掩码测试

### 9.1 MASK-H2～H16

固定：

```text
f0 = 25 kHz
H1 = 5 mVpeak / 10 mVpp / 0°
目标Hn = 20 mVpeak / 40 mVpp / 0°
n = 2, 3, ... 16
```

每次只开启一个目标Hn，runner自动生成USER掩码。由此覆盖50～400 kHz，并专门验证：

- H2～H16的掩码位置没有错一位；
- 基波只有5 mVpeak且不是最大分量时仍能识别；
- 活动谱线幅值正确；
- 其余非活动H2～H16没有被错误显示。

### 9.2 ORDER-400K

固定目标谱线为400 kHz，分别令其作为H2～H16：

```text
f0 = 400 kHz / n
H1 = 5 mVpeak
Hn = 25 mVpeak
n = 2, 3, ... 16
```

这一组区分“绝对频率响应”和“谐波阶次/发生器内部缩放”。若同为400 kHz、同为
25 mVpeak的结果在不同阶次间出现明显系统差异，校准表不能只按绝对频率索引，必须增加
`harmonic_order`维度。

验收：

- 目标谱线频率误差目标`≤500 Hz`、底线`≤1 kHz`；
- 校准后峰值误差目标`≤3 mV`、底线`≤5 mV`；
- 非活动谱线输入等效峰值目标`<1 mV`；
- 基频识别不得把400 kHz最大谱线误认成基波。

## 10. H2：这台DG4202的逐点端到端校准

### 10.1 10～500 kHz密集表

使用HARM＋USER且关闭H2～H16，仅保留基波：

```text
frequency = 10 kHz ... 500 kHz，步进500 Hz，共981点
H1 = 50 mVpeak / 100 mVpp
```

每点计算：

```text
Utheory(f) = 本地manifest设置峰值
Uch1(f) = CH1原始波形FFT峰值
Uch2(f) = CH2原始波形FFT峰值
Acode(f) = FPGA码序列FFT峰值

Ksrc(f) = Uch1(f) / Utheory(f)
Gfront(f) = Uch2(f) / Uch1(f)
Kcode(f) = Acode(f) / Uch2(f)
Ke2e(f) = Acode(f) / Utheory(f)
Cjudge(f) = Utheory(f) / Acode(f)
```

最终比赛使用`Cjudge(f)`，CH1/CH2的本地FFT结果用于解释信号源、模拟前端和ADC/数字链
各自的偏差。DG query/profile中的幅度字段不得代替`Utheory`或`Uch1`。

### 10.2 幅度锚点

```text
frequency = 10 / 50 / 100 / 200 / 300 / 400 / 500 kHz
peak = 5 / 10 / 25 / 50 / 100 mV
```

再选择H2、H8、H16各重复一组幅度阶梯，基波保持5 mVpeak。用于判断是否需要：

```text
C(f)                         # 线性系统，只需频率表
C(f, A)                      # 有可重复的幅度非线性
C(f, A, harmonic_order)      # 还有阶次相关缩放
```

优先使用最简单且通过独立验证的模型，不能因为训练数据多就默认使用高维查表。

### 10.3 独立复验

- 第一轮按升频顺序生成训练表；
- 第二轮按降频顺序重复所有500 Hz点，检查迟滞和重复性；
- 另从全带随机抽取至少100个点，在不重新拟合的情况下作为holdout；
- 幅度锚点至少重复三轮，顺序分别为升幅、降幅和随机；
- holdout最大幅值误差必须`≤5 mV`，目标`≤3 mV`。

## 11. H3：相位、Vpp和crest factor测试

先固定：

```text
f0 = 50 kHz
H1 = 40 mVpeak
H2 = 25 mVpeak
H3 = 15 mVpeak
```

H2、H3相位分别取`0° / 90° / 180° / 270°`，形成16组组合。谱线峰值和真RMS理论上
不随相位变化，但整体Vpp与crest factor会变化。

再执行一对幅度完全相同、峰均比明显不同的正式`u_a`用例：

| case_id | f0 | 谱线峰值与相位 | 理论Vpp | 理论真RMS | crest factor |
|---|---:|---|---:|---:|---:|
| UA-CREST-LOW | 40 kHz | H1 40 mV@0°；H3 30 mV@270°；H5 20 mV@300° | 109.409 mV | 38.079 mV | 1.437 |
| UA-CREST-HIGH | 40 kHz | H1 40 mV@0°；H3 30 mV@180°；H5 20 mV@0° | 180.000 mV | 38.079 mV | 2.364 |

表中Vpp按`sin(2πn f0t + φn)`高密度数值计算。正式执行前，自动化首个相位用例应以
CH1直接波形确认DG4202的相位约定；确认后固定同一公式，不得逐例手工调相凑数。

验收：

- 两组各条谱线峰值结果应一致并满足5 mV底线；
- 两组真RMS应一致；
- Vpp应分别匹配各自manifest，而不是错误地只由谱线幅值之和计算；
- FPGA算法不得因最大瞬时值不同而改变谱线幅值标定。

## 14. 分析、校准与显示值口径

### 14.1 理论值—示波器FFT—FPGA码值对应关系

```text
Utheory(f,n,A) = 本地DG设置manifest计算值
Uch1(f,n,A) = RTM CH1原始数据FFT值
Uch2(f,n,A) = RTM CH2原始数据FFT值
Acode(f,n,A) = FPGA码序列FFT值

Ksrc = Uch1 / Utheory
Gfront = Uch2 / Uch1
Kcode = Acode / Uch2
Ke2e = Acode / Utheory
Cjudge = Utheory / Acode
```

ESP32-P4未来显示使用`Cjudge`或其经过独立验证的降维形式，使结果对齐这台自带DG4202
的设置值。示波器FFT用于测量真实模拟链路和判责，不用于把比赛参考重新定义为CH1；
DG配置回显则既不能代替示波器FFT，也不能作为实际输出幅度。

### 14.2 不允许的“校准”方式

- 不把测得值吸附到常见的5/10/20/50/100 mV档位；
- 不通过LAN、USB或SCPI把DG设置值传给ESP32-P4；
- 不把DG的设置回显当成真实模拟输出测量值；
- 不只保存RTM自动测量框或屏幕FFT，必须保存原始波形并在本地重算；
- 不用训练点本身证明校准成功；
- 不假设最大谱线就是基波；
- 不逆补偿1 MHz以上FIR阻带，使干扰重新出现在结果中；
- 不同时叠加“示波器本征标定”和“DG端到端标定”造成重复补偿。

### 14.3 校准身份

校准文件至少绑定：

```text
DG4202型号、序列号和固件
CH1、50 Ω显示模式、谐波模式和幅值单位
固定输出线缆
AD8065前端版本与AD9226通道
FPGA bitstream/ELF、FIR哈希、抽取率和实际输出采样率
FFT长度、窗函数与幅值算法版本
训练数据manifest与holdout报告哈希
```

任一绑定项改变，生成新的`calibration_id`，旧表不得静默复用。

## 15. 总验收门槛

| 类别 | 目标 | 硬底线/停机条件 |
|---|---:|---:|
| 活动谱线峰值误差 | `≤3 mV` | `≤5 mV` |
| 总Vpp、真RMS误差 | `≤3 mV` | `≤5 mV` |
| 基频误差 | `≤500 Hz` | `≤1 kHz` |
| 非活动谐波/新增互调 | `<1 mVpeak`输入等效 | 不得造成有效谱线误判或5 mV超差 |
| H2～H16掩码 | 15/15逐阶正确 | 任一错位即FAIL |
| 同频不同阶次 | 校准后峰值极差`≤2 mV` | 任一点超过5 mV即FAIL |
| 四层对应数据 | 每条活动谱线同时具有`Utheory/Uch1/Uch2/Acode` | 任一缺失则不得进入校准表 |
| FIR干扰抑制 | `≥50 dB` | `u_b`恢复仍须满足5 mV |
| 输入安全 | CH1`≤0.55 Vpp` | 超限停止升幅 |
| ADC节点安全 | CH2正常`≤2.35 Vpp` | `>2.5 Vpp`、削顶、自激或OTR立即OFF |
| 数据链 | 零CRC/序号/frame/FIFO/drop错误 | 任一错误即该点FAIL |
| 自动化恢复 | 完整profile一致，最终OFF | 恢复歧义则锁止后续写入 |

## 17. 推荐执行顺序

```text
WaveBench完整USER/逐阶幅相接口离线验收
→ 低幅H2～H5实物烟测
→ H2～H16掩码和ORDER-400K
→ 10～500 kHz/500 Hz逐点表
→ 幅度锚点和独立holdout
→ 相位/crest factor
→ u_a/u_b正式矩阵
→ u_b + u_J
→ 校准冻结与最终恢复
```

当前最合理的下一步不是手工开始配置16阶谐波，而是先补齐WaveBench的安全公共控制和
run-plan入口。接口一旦通过离线与低幅实物门禁，后续所有矩阵都应由manifest驱动自动
执行，人工只负责确认接线、启动批次和处理真实FAIL。
