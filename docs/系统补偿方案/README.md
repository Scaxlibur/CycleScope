# 系统补偿方案与联调资料

本目录把“模拟前端实际增益”“标量校准”“P4逐频补偿”和“FPGA/P4联调”分开记录。最终原始证据与校验入口见 [验收证据索引](../验收证据索引.md)。

## 当前运行事实

- P4 当前源包含 10～500 kHz 的分段线性逐频幅值补偿；运行时资产 profile 为 `0xC5DCDE41`。
- 它只在上游身份严格匹配 `calibration_id=25030 / scale=516 µV/code / offset=-6761 µV / filter_profile=1 / 4,062,500 S/s / 8192` 时启用。
- 校正位置在频率精修和 `project_at_frequency()` 之后；谱线、RMS、Vpp 与带内频谱使用校正值，峰值候选检测保持标量频谱。
- 10 kHz 以下、500 kHz 以上和 1 MHz 以上阻带/干扰不外推、不逆补偿。

上述内容并不代表所有旧文档中的“未来要做”描述都已生效。以 [前端增益与逐频补偿指南](前端增益与逐频补偿指南.md) 与最终 `fit-v2/p4-asset-v2` manifest 为准。

## 不能混用的三类数

1. AD8065 的理论 `Gfb/Gamp`：仅用于拓扑和量程预估；
2. CSLP 标量 `516 µV/code, -6761 µV`：上游帧的输入端标定语义；
3. P4 频响表 `input_uv_per_code(f)`：只用于 `C5DCDE41` 的带内逐频幅值校正。

任何前端、电阻、ADC通道、filter profile、采样率或帧长改变，都必须重新校准、重新生成资产并验证，不能沿用 `25030` 或 `C5DCDE41`。
