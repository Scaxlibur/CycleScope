# CycleScope 信号前端全链路测量方案

> **当前范围（2026-08-02）：** 本文主体保留 M11 设计与执行方法。最终 `fit-v2` 已冻结普通输入 `≤250 mVpp`、`25030/516/-6761` 与 `C5DCDE41`；三个 450 mVpp 压缩点已从 fit、holdout 和验收排除。任何下文把 450/500 mVpp 写成“下一步”或“正式点”的地方，均为历史压力计划，不得覆盖[测试与证据索引](../测试与证据索引.md)的当前结论。

## 1. 目的与适用范围

本文用于验收以下真实信号链：

```text
DG4202 CH1
  → 装置 BNC / 放大器输入
  → AD8065 同相放大器（RF = 1.608 kΩ、RG = 200.2 Ω）
  → AD9226 通道 A（ADC 模块维持真实 50 Ω输入负载）
  → FPGA 65 MSPS 采集
  → FIR 低通 / 16 倍抽取
  → 4.0625 MS/s、8192 点、S16_LE
  → Zynq PS / CSLP-UDP / 电脑离线分析
```

本轮不验收 ESP32-P4 和 LVGL，但必须验证送到 P4 之前的数据已经具备完成 G 题的幅值、频率、时域和抗干扰条件。

本文依据：

- `docs/G题_周期信号测量分析装置/full.md`；
- `docs/主办方答疑/` 中现有全部答疑版本；
- [CSLP G题采样与处理 Profile](../协议与接口/CSLP-G题采样与处理-Profile-v0.1.md)；
- [模拟前端放大器调试注意事项](模拟前端放大器调试注意事项.md)；
- 同步执行计划 `tool-of-rei/fpga-history/M11-真实全链路FIR与信号处理压力测试计划.md`。

该计划已与本文同步更新；第 5 节列出本次更换前端后的关键差异。

## 2. 主办方要求形成的测试边界

| 项目 | 正式边界 |
|---|---:|
| `u_a` 整体峰峰值 | 100～250 mVpp |
| `u_a` 全部频率分量 | 10～200 kHz |
| `u_b` 整体峰峰值 | 50～250 mVpp |
| `u_b` 全部频率分量 | 10～500 kHz |
| 信号组成 | 基波加 1 个或 2 个谐波，频率严格保持谐波关系 |
| 单条基波/谐波最小幅值 | 5 mVpeak，即 10 mVpp 单音等效量级 |
| 干扰 `u_J` | 200 mVpp 单频正弦，`f_J >= 1 MHz`，没有规定最高频率 |
| 输入直流分量 | 无 |
| 频率步进 | 基频为 500 Hz 的整数倍 |
| FFT 栅格 | 不大于 500 Hz |
| Vpp、真 RMS、谱线峰值幅值误差 | 绝对值不大于 5 mV |
| 基频误差 | 绝对值不大于 1 kHz |
| 响应时间 | 启动相应测量功能后不超过 2 s |
| 评分幅值基准 | 原则上以工作正常的信号发生器 50 Ω模式设置值为准 |
| 外部供电 | 仅一路 5 V 直流稳压电源；内部允许变换出其他电压 |

特别注意：装置输入端并未被主办方强制要求为 50 Ω，但评分基准仍是信号发生器的设置值。因此既要记录 DG 设置值，也要测量真实放大器输入，不能把二者混成一个量。

## 3. 测量接法及结论

### 3.1 正式接线

```text
DG4202 CH1（50 Ω负载语义、0 V offset）
    │
    ├──────────── AD8065 同相放大器 IN / 装置 BNC
    │                 └── RTM2032 CH1：高阻、DC 耦合，测 Vin
    │
    └── AD8065 OUT ── 输出串联匹配电阻 ── AD9226 输入节点
                                             │（ADC 自身为唯一 50 Ω负载）
                                             └── RTM2032 CH2：高阻、DC 耦合，测 Vadc

AD9226 A → FPGA FIR/抽取 → LAN → 电脑保存 8192 点帧
```

该接法正确，约束如下：

1. RTM CH1 和 CH2 都必须保持高阻。CH2 若误设为 50 Ω，会与 ADC 的 50 Ω并联成约 25 Ω，增益、失真和频响结果全部失效。
2. ADC 模块是放大器输出端唯一的正式 50 Ω负载，测试期间不得拔掉后用 CH2 高阻冒充负载。
3. DG 的“50 Ω”是幅值显示/负载语义，不代表放大器输入一定已匹配。必须实测
   `Ksrc(f) = Vin_RTM / Vset_DG`。接近 1 通常表示输入近似匹配；接近 2 通常意味着输入近似高阻。
4. 竞赛等效误差以 DG 设置值计算；CH1 用于解释信号源、线缆和输入阻抗造成的差异；CH2 用于把放大器问题与 ADC/FIR 问题分开。
5. 一般测试优先使用已补偿的高阻探头和短接地弹簧。高频混叠测试不得使用长 BNC 支路或长鳄鱼夹形成明显 stub；必要时使用高带宽有源探头。
6. 两个示波器通道必须来自同一次 acquisition。不得先触发 CH1、再触发 CH2 后把两条非同窗波形当作幅相响应。

### 3.2 探头和通道预校验

正式接入放大器前，把 CH1、CH2 探头同时接到一个带真实 50 Ω终端的低幅度正弦节点，至少在 `10 kHz / 500 kHz / 3 MHz` 做通道比对：

- 核对探头衰减倍率与 RTM 菜单设置一致；
- 记录 CH2/CH1 的幅值比和相位差，生成通道修正量；
- 交换两支探头复测一次，区分探头误差与示波器通道误差；
- 最小 10 mVpp 谱线测试若 10×探头信噪比不足，可改用经过负载影响验证的低噪声高阻测法，但必须重新记录探头配置，不能静默换接法。

## 4. AD8065 增益与量程预算

当前前端沿用同相结构，并按“运放输出串联约 50 Ω、AD9226 输入为 50 Ω负载”处理：

```text
RF = 1.608 kΩ = 1608 Ω
RG = 200.2 Ω

反馈网络理想增益 Gfb = 1 + RF/RG
                     = 1 + 1608/200.2
                     = 9.031968032 V/V

若 Rs = 50 Ω、RL = 50 Ω：
匹配网络理论分压 Kmatch = RL/(Rs + RL) = 0.5
负载端理论增益 G50      = Gfb × Kmatch
                         = 4.515984016 V/V

当前示波器目测粗估 Grough ≈ 4 V/V（非正式测量）
```

上述 4.515984 倍还假设 `RF` 从 AD8065 输出引脚、即串联匹配电阻之前取反馈。若反馈取样位于匹配电阻之后，负载端不会按 1/2 简单分压，量程预算将完全不同；A 阶段必须断电确认反馈取样节点。

若目测 4 倍准确，则会比精确 50 Ω分压理论值低约 11.4%；但目前这个差值也可能只是示波器读数精度、探头或估算方式造成。A/C 阶段必须分别测量 AD8065 输出引脚和 ADC 输入节点，冻结实际 `Gfb`、`Kmatch`、输出串联电阻与加载增益；在正式数据出现前，不能把 4.000 当作硬件常数。

按 AD9226 模块标称 `10 Vpp / 4096 code`：

```text
ADC 端 1 code                    = 2.44140625 mV/code
按理想 4.515984 倍折算到输入端  ≈ 0.540614458 mV/code
若仅按目测 4 倍作灵敏度下界参考 ≈ 0.610351562 mV/code
```

| 装置输入 | 用途 | 精确 50 Ω理论 ADC 节点 | 理论码程 | 目测 4 倍参考节点 |
|---:|---|---:|---:|---:|
| 10 mVpp | 5 mVpeak 最小谱线单独灵敏度检查 | 0.04516 Vpp | 18.50 code p-p | 0.040 Vpp |
| 50 mVpp | `u_b` 最小整体输入 | 0.22580 Vpp | 92.49 code p-p | 0.200 Vpp |
| 100 mVpp | `u_a` 最小整体输入 | 0.45160 Vpp | 184.97 code p-p | 0.400 Vpp |
| 200 mVpp | 单频干扰 `u_J` | 0.90320 Vpp | 369.95 code p-p | 0.800 Vpp |
| 250 mVpp | `u_a/u_b` 最大整体输入 | 1.12900 Vpp | 462.44 code p-p | 1.000 Vpp |
| 450 mVpp | `250 mVpp u_b + 200 mVpp u_J` 理论上界压力 | 2.03219 Vpp | 832.39 code p-p | 1.800 Vpp |
| 500 mVpp | 非赛题余量点 | 2.25799 Vpp | 924.87 code p-p | 2.000 Vpp |

这里的 `450 mVpp` 是两个输入峰峰值之和形成的保守上界。按理论加载增益，最小 5 mVpeak 谱线约有 9.25 code peak；即使目测 4 倍最终成立，也约有 8.19 code peak。量化上可用，但必须通过 weak-line 用例实测噪声和杂散余量。

[ADI AD8065/AD8066 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/AD8065_8066.pdf)给出的相关边界是：

- AD8065 是单位增益稳定、145 MHz 的电压反馈 FastFET 运放，±5 V属于正式表征条件；
- ±5 V下输出电流指标为 35 mA。500 mVpp 输入、精确 50 Ω串联匹配时，运放输出约 4.516 Vpp，匹配支路峰值电流约 22.58 mA，有余量但不算奢侈，450/500 mVpp 必须做热机失真和压缩测试；
- 数据手册的一阶模型交越频率约 65 MHz；当前噪声增益 9.03197 对应闭环 `-3 dB` 频率约 7.20 MHz。500 kHz 有效带应有余量，但 4～10 MHz 的 CH2 幅值可能已经包含明显模拟滚降，数字 FIR 衰减仍必须用 `CH2 → FPGA` 归一化；
- 数据手册建议反馈电阻约 300 Ω～1 kΩ。当前 `RF = 1.608 kΩ` 超出建议范围，且 `RF || RG ≈ 178.0 Ω` 会与反相端总输入电容共同影响环路，因此必须检查峰化、振铃、相位和噪声；
- 输出串联电阻有利于隔离 ADC/探头电容负载，但其真实阻值和分压必须实测。

理论值与目测粗估都不能代替校准。安全上按理论 4.516 倍留余量，电压换算按端到端实测冻结并分配新的 `calibration_id`。

## 5. M11 的本次同步更新

更换前端后，M11 必须同步修改以下事实：

| 原 LMH6609 版本 | AD8065 新前端的影响 | 本方案处理 |
|---|---|---|
| LMH6609 同相理想增益 5.0725 | AD8065 反馈增益 9.032，50 Ω理论加载增益 4.516，示波器目测粗估约 4 | 同时记录 `Gfb/Kmatch/Gamp`，正式校准只信定量测量 |
| 500 mVpp 对应约 2.536 Vpp ADC 节点 | 新前端目测参考约 2.0 Vpp，精确 50 Ω理论约 2.258 Vpp | CH2 正常上限收紧到 2.35 Vpp，2.5 Vpp立即停机 |
| 输入等效比例名义 0.4813 mV/code | 50 Ω理论值约 0.5406 mV/code；目测 4 倍仅对应粗略参考 0.6104 | 清除旧校准，重新生成非零 `calibration_id` |
| 只测 CH1/CH2 总加载增益 | 目测约 4 倍尚不能确认与理论 4.516 是否真实存在差值 | A/C 增加运放输出引脚与 ADC 节点分层定量测量 |
| 685 Ω反馈网络风险 | AD8065 的 1.608 kΩ也超出数据手册建议范围 | 保留小信号阶跃，并增加匹配网络分压、7.2 MHz附近画像 |
| 原安全、FIR、LAN和长稳矩阵 | 数字链和赛题输入边界没有改变 | 继续复用，幅度期望值和前端事实全部更新 |

M11 的 ARB、LAN完整性、FIR 阻带、响应时间和长稳原则不变；所有旧 LMH6609 标定值和前端哈希作废。

## 6. 安全硬门槛

1. 正式证据必须使用整机单路 5 V 外部供电及装置内部电源变换。使用台式电源分别提供 `+5 V/-5 V` 的结果只能作为预调试，不能作为赛题供电合规结论。
2. DG CH1 固定为 50 Ω负载语义、0 V offset、burst/modulation/sweep 关闭。改变函数、频率、幅值或 ARB 前先输出 OFF。
3. 首点从 `100 kHz / 10～50 mVpp` 开始，按输入实测值单调升高；450 mVpp 和 500 mVpp 最后执行。
4. DG 命令不得超过 `500 mVpp`；CH1 实测不得超过 `550 mVpp`。自动化配置中的
   `max_source_vpp` 也必须收紧为 `0.5`，不能继续依赖直驱 ADC 时的 `2.0` 上限。
5. CH2 正常目标不超过 2.35 Vpp；把 `2.5 Vpp`、异常直流偏置、削顶、持续振铃或自激作为立即 OFF 的停机门槛。
6. 任一点出现 ADC OTR、FPGA/FIFO 溢出、帧丢弃、采样码异常跳变、供电过流或器件异常升温，立即关闭 DG，原始证据按失败点保存，不自动重试掩盖问题。
7. 所有仪器、ADC、FPGA 与放大器使用同一信号地。示波器地夹只能接信号地，严禁误接内部负电源轨。
8. 高频测试前先以 200 mVpp 以下检查放大器增益峰化；未知频率点不得直接使用 450/500 mVpp。
9. 本轮正式计划的频率硬上限为 10 MHz；任何 `>10 MHz` 点必须进入单独标记的实验计划，不能由正式矩阵自动连续扫入。
10. RTM 两通道均保持高阻。每次 campaign 开始、每个高幅阶段前和结束后均回读确认；
   自动化若只能门禁一个通道，必须先补齐双通道 fail-closed 检查，不能只验证 CH1。
11. 最终状态固定恢复为 `SIN / 100 kHz / 50 mVpp / 50 Ω / 0 V offset / OFF`，并回读留证。
12. 一个测量用例启动后不再手动调整放大器、电阻、量程档位或补偿参数；所有变化只能在用例之间完成并记录。

## 7. 每个测试点的证据闭环

每个正式点执行同一顺序：

1. 记录仪器 ID、校准状态、DG CH1 profile、RTM CH1/CH2 高阻状态、外部 5 V、电流和内部关键电源轨。
2. DG 输出 OFF 下设置波形、频率、幅值、相位或 ARB，并保存设置/ARB manifest 与哈希。
3. 显式打开 DG，等待至少 1 s 或已验证的稳定时间。
4. RTM 单次 acquisition 同时保存 CH1、CH2 原始波形、元数据和截图；不得只保存自动测量框里的一个 Vpp 数字。
5. 采集与 DG ON 时间窗相交的至少 22 个完整 LAN 帧；量程边界、最小谱线、第三项组合和 10 MHz 边界点至少 64 帧。
6. 显式关闭 DG并回读状态。
7. 计算并保存 CH1、CH2、FPGA 三层分析结果、协议完整性结果和仪器不确定度。

刺激 ON/OFF 窗口、RTM acquisition 和 LAN 帧时间线不相交时，该点无效；不得从错误时间窗里挑选“看起来正常”的帧。

## 8. 测试矩阵

### A. 断电、探头与供电预检

- 断电测量放大器输入端直流阻抗、ADC 输入端直流阻抗和地连续性；记录实际值，不根据“50 Ω模块”名称猜测。
- 断电复核 AD8065 确为同相拓扑，确认 `RF` 取样位于匹配电阻前还是后，并实测/记录 `RF`、`RG` 和输出串联匹配电阻；与 1.608 kΩ、200.2 Ω或目标 50 Ω不符时重新计算。
- 完成第 3.2 节双通道/探头比对。
- 仅接一路 5 V 外部电源，记录冷机和热机后的 5 V 输入电流、内部正负电源轨、输出直流偏置和器件温度。
- DG OFF、输入保持正式源阻抗时，以 RTM 全带宽检查 CH2 是否有持续振荡或固定高频杂散。
- ADC 50 Ω负载保持连接，以 `100 kHz / 50 mVpp` 小信号方波做一次稳定性预检，记录 AD8065 输出引脚和 CH2 的过冲、振铃频率和稳定时间；持续振荡直接停止，过冲超过 10% 时先排查 1.608 kΩ反馈网络、输出匹配、电容负载和布局，再进入大信号矩阵。

### B. 零输入、噪声和偏置

DG CH1 保持连接但输出 OFF，采集 CH1、CH2 和至少 64 个 FPGA 帧：

- CH1/CH2：平均值、RMS、峰峰值、0～500 kHz 积分噪声和最大离散杂散；
- FPGA：码均值、AC RMS、码范围、固定谱线、离群点率和 OTR；
- 把 CH2 噪声除以实测加载增益，计算输入端等效噪声；
- 把 FPGA 噪声按当前端到端换算折回装置 BNC 输入端。

工程目标为输入端等效噪声不大于 `0.5 mVrms`，0～500 kHz 固定杂散尽量低于 `1 mVpeak`。若仪器噪声底高于目标，必须写成测量上限，不能把“未看到”写成零。

### C. DG 设置值与真实输入关系

先在 `100 kHz / 20、50、100 mVpp` 测量 `Ksrc = Vin/Vset`，再于 `10 kHz / 500 kHz / 3 MHz` 复测 100 mVpp：

- 判断放大器输入是近似 50 Ω还是高阻；
- 检查 `Ksrc` 是否随频率或幅度明显变化；
- 记录 DG 设置误差与真实 BNC 输入，不使用示波器闭环把 DG 调到另一个设置值后冒充竞赛等效点。

RTM2032 只有两个通道，无法同时观察 `Vin/Vopamp/Vadc` 三个模拟节点。因此在
`100 kHz / 50 mVpp` 以及 `500 kHz / 3 MHz` 代表点采用两次稳定刺激采集：

1. CH1 固定测 `Vin`，CH2 临时测 AD8065 输出引脚，得到 `Gfb = Vopamp/Vin`；
2. 保持 DG 设置不变，CH2 返回 ADC 输入节点，得到 `Gamp = Vadc/Vin`；
3. 用两次采集的 CH1 幅值一致性作门禁，再计算 `Kmatch = Gamp/Gfb`。

这组顺序测量只用于冻结匹配网络；正式端到端测试仍按 CH1/CH2 同次 acquisition 执行。

`Ksrc` 不接近 1 并不自动违反题目，但必须进入 DG 设置值到 FPGA 结果的端到端校准，并重新核算最大真实输入和输出摆幅。

### D. 加载增益、线性和动态范围

频率使用：

```text
10 / 100 / 200 / 500 kHz
```

每个频率依次使用：

```text
10 / 50 / 100 / 250 / 450 / 500 mVpp（DG 50 Ω设置值）
```

说明：10 mVpp 是最小 5 mVpeak 谱线的单音灵敏度点，不是题目规定的整体输入下限；450 mVpp 是组合上界压力；500 mVpp 是余量点。

每点计算：

```text
Gfb(f, A)  = AD8065 输出引脚基波峰值 / CH1 基波峰值（仅代表诊断点）
Kmatch     = Gamp / Gfb（仅在双采集一致性门禁通过后使用）
Gamp(f, A) = CH2 基波峰值 / CH1 基波峰值
Kadc(f, A) = FPGA 基波 code peak / CH2 基波峰值
Ke2e(f, A) = FPGA 基波 code peak / DG 设置峰值
```

同时记录增益压缩、输出偏置、THD、SFDR、二/三次谐波、码域范围、离群点和 OTR。450/500 mVpp 点还要在热机和最低预期单路 5 V 输入条件下复测。

### E. 10～500 kHz 幅频、相频和校准曲线

主扫使用 `100 mVpp`：

```text
10 / 10.5 / 20 / 50 / 100 / 200 / 300 / 400 /
450 / 475 / 490 / 500 kHz
```

- 先升频、再降频，识别热漂移、滞回和自动量程伪差；
- 在 `10 / 100 / 500 kHz` 追加 10 mVpp 最小谱线复测；
- 在 `50 / 250 / 450 mVpp` 追加 `10 / 200 / 500 kHz` 交叉点，验证幅频补偿不依赖单一幅度；
- 分别得到放大器 `CH2/CH1`、ADC/FIR `code/CH2` 和整链 `code/DG设置值` 的幅相响应；
- 用正弦拟合、相干投影或经窗增益校正的频谱估计，不用时域 Vpp 猜小残余谱线。

校准曲线拟合点之外，再用以下保留点独立验证，避免“拿拟合数据验证拟合”：

```text
15 / 75 / 150 / 250 / 350 / 425 / 485 kHz
```

### F. 1～3 MHz 数字 FIR 阻带

以装置 BNC 端 `u_J = 200 mVpp` 单音为正式幅度，先执行：

```text
1.0 / 1.05 / 1.1 / 1.25 / 1.5 / 1.75 / 1.9 /
2.0 / 2.00625 / 2.05625 / 2.1 / 2.25 / 2.5 / 2.75 / 3.0 MHz
```

再从当前 Q1.17 FIR 的理论响应中选择 8 个阻带残余最大的非重复点。对每个点：

- 用 CH2 实测送入 ADC 的干扰峰值；
- 按抽取后的折叠频率在 FPGA 序列中做正弦最小二乘或相干投影；
- 计算 `CH2 → FPGA` 的衰减下界，目标不低于 50 dB；
- 低于噪声底时报告带置信区间的衰减下界，不写“无限 dB”。

可以另做更高幅度数字 FIR 压力点，但必须明确标为工程压力，不能替代题目规定的 200 mVpp 干扰结果。

### G. 题目第 1、2 项多音等效矩阵

全部波形使用基波加 1 个或 2 个正弦谐波，各频率为 500 Hz 整数倍；矩阵中至少包含一组“基波 + 1 个谐波”和一组“基波 + 2 个谐波”。ARB 文件必须保存每条谱线的频率、峰值幅值、相位、合成 Vpp、真 RMS 和 crest factor。

| 用例 | 整体输入 | 建议频率构成 | 重点 |
|---|---:|---|---|
| A-low | 100 mVpp | 10 kHz 基波及不超过 200 kHz 的 1～2 条谐波 | `u_a` 下边界 |
| A-edge | 250 mVpp | 40 / 120 / 200 kHz | `u_a` 幅度和频带上边界 |
| B-low | 50 mVpp | 10～500 kHz 内基波及 1～2 条谐波 | `u_b` 最低整体码程 |
| B-edge | 250 mVpp | 100 / 300 / 500 kHz | `u_b` 幅度和频带上边界 |
| weak-line | 50～250 mVpp | 至少一条谱线固定为 5 mVpeak，基波不作为最大分量 | 最小谱线和“基波不一定最强” |

每个用例至少做一组高 crest factor 相位和一组低 crest factor 相位。离线从 FPGA 帧恢复并比较：整体 Vpp、真 RMS、基频、全部正频率谱线的峰值幅值和频率。此处的幅值比较基准是 DG/ARB manifest 的设置值，CH1/CH2用于归因。

### H. 题目第 3 项组合输入

从 G 中选择 B-low、B-edge 和 weak-line 三组 `u_b`，分别叠加 `200 mVpp` 单频正弦干扰：

```text
f_J = 1.0 / 1.5 / 2.0 / 2.5 / 3.0 MHz
```

优先使用 DG CH1 的单通道合成 ARB，使装置仍只接收一根电缆。必须在 manifest 中分别保存 `u_b` 和 `u_J` 的设置，不以总波形 Vpp代替干扰的 200 mVpp 定义。

检查：

- CH2 无削顶、恢复异常和增益压缩；
- FPGA 输出中 `u_J` 衰减不低于数字 FIR 门槛；
- 10～500 kHz 内没有放大器/ADC 新产生的显著互调线；
- 抑制干扰后，`u_b` 的 Vpp、真 RMS、基频和每条谱线仍满足误差门槛；
- 总输入接近 450 mVpp 的高 crest factor 用例至少保存 64 帧。

### I. 10 MHz 正式上限与高频实验扩展

本轮正式信号前端 campaign 把实物干扰频率上限定为 10 MHz。F 阶段完成 1～3 MHz 后，继续以装置 BNC 端 `u_J = 200 mVpp` 测试：

```text
4 / 5 / 7.2 / 7.5 / 10 MHz
```

每点同时保存 CH1、CH2 和 FPGA 数据，按采样后的实际数字频率计算 `CH2 → FPGA` 衰减；5 MHz 和 10 MHz 再各选择一组 B-edge `u_b` 做组合复测。正式目标仍是干扰衰减下界不低于 50 dB，且恢复后的 `u_b` 指标满足 5 mV 门槛。

10 MHz 以上不作为本轮长稳测试的前置条件，只作为实验性测量。实验阶段应优先研究 ADC 前折叠最危险的频率族：

```text
f_alias = abs(((f_J + Fs/2) mod Fs) - Fs/2),  Fs = 65 MHz

f_J = n × 65 MHz
f_J = n × 65 MHz ± {10 / 100 / 250 / 500 kHz}
```

其中 `n` 按仪器能力选取；DG4202 可覆盖时可从 `n = 1` 开始，再决定是否扩展到 130/195 MHz 附近。实验性高频点遵守以下原则：

1. 始终从 200 mVpp 或更低开始，不使用 450/500 mVpp。
2. 同时观察 CH1、CH2 和 FPGA 折叠谱线，不能把信号源、探头或示波器的带宽滚降全部算成前端衰减。
3. 若干扰在 FPGA 有效带产生大于 `1 mVpeak` 的输入端等效谱线，记录为抗混叠风险，并据此决定是否增加独立模拟低通。
4. 若要宣称完成高频组合验证，仍需把最坏点与 `u_b` 实际叠加；单做干扰音只能形成风险画像。

这个分层边界必须写进报告：`1～10 MHz` 是本轮正式实测覆盖，`>10 MHz` 是实验性扩展。由于主办方答疑没有给干扰最高频率，测到 10 MHz 不能宣称已经穷尽 ADC 前混叠风险；更高频结论只能结合实验结果、模拟低通拓扑和器件带宽给出。

### J. 响应时间、热机和长稳

- 从 FPGA `ENABLE_STREAM` 或等效启动事件到首个完整、状态有效的 8192 点帧，工程目标不超过 250 ms，为 P4 分析和 LVGL 留出 2 s 总预算。
- 选择 `250 mVpp u_b + 200 mVpp u_J` 中实测 crest factor 安全、最容易暴露问题的一组，运行 10,001 帧，约 500 s。
- 首、中、末复测 CH1/CH2，记录加载增益、零偏、供电电流和温度；每 1000 帧计算一次端到端增益。
- CRC、包序号、frame_id、时间戳、OTR、FIFO、drop、socket、NIC 与 GEM 错误全部要求为零。
- 标称单路 5.00 V 完成后，在最低预期外部供电点复测 450/500 mVpp 和频带边界；仍只能使用单路外部电源。

## 9. 分层分析与校准方法

### 9.1 三个事实层

每条谱线同时保留下列结果：

```text
源/输入层：DG 设置值、CH1 实测值
模拟层：  CH2 实测值、Gamp、失真和相位
数字层：  FPGA code peak、频率、FIR衰减和帧状态
```

这样可以明确判责：

- `CH1/DG` 异常：输入阻抗、信号源语义、线缆或仪器问题；
- `CH2/CH1` 异常：放大器、输出负载、供电或模拟滤波问题；
- `code/CH2` 异常：ADC、采样时序、码型、FIR或抽取问题；
- 三层单独正常但 `code/DG` 超差：端到端校准或误差预算问题。

### 9.2 软件补偿

放大器逐点波特图可用于软件补偿，但正式使用的应是“DG 50 Ω设置值到 FPGA 码”的端到端校准，而不是只补偿裸放大器：

1. 零输入求 `offset_code`；
2. 用 50/250 mVpp 的保留幅度点求线性增益，不能只用一个点；450 mVpp 压缩点不参与当前模型；
3. 用 E 的训练频点生成 10～500 kHz 平滑幅相校准表；
4. 用保留频点和多音矩阵独立验证；
5. 校准只在 10～500 kHz 有效，不得逆补偿 1 MHz 以上阻带或高频混叠残余；
6. 放大器、电阻、ADC 通道、滤波器、探头/负载拓扑或校准表任一改变，都分配新的非零 `calibration_id`。

正式误差按 DG 设置值计算；CH1 实测值用于误差归因和仪器不确定度，不应用来把一个对 DG 设置值超差的结果“重新定义为通过”。

### 9.3 FFT 与幅值口径

- FPGA 输出样点率为 `4,062,500 sample/s`，8192 点频点间隔为
  `495.9106445 Hz`，满足不大于 500 Hz；
- 频谱分量幅值统一使用单边谱的正弦峰值，不使用 Vpp 或 RMS 冒充；
- 非相干采样必须补偿窗函数相干增益和单边谱 2 倍系数；
- 小残余、阻带和互调优先使用正弦最小二乘/相干投影；
- 真 RMS 按校准后的 `sqrt(mean(x^2))` 计算，不能用基波 RMS 代替多音真 RMS；
- 基波不保证是最高谱线，离线判据也不得依赖“最大 bin 就是基波”。

## 10. 验收门槛

| 类别 | 工程冻结目标 | 赛题/安全底线 |
|---|---:|---:|
| RTM 负载 | CH1、CH2 均为高阻 | 任一通道误设 50 Ω则该点作废 |
| 输入/输出安全 | `Vin <= 0.55 Vpp`、`Vadc <= 2.35 Vpp` | `Vadc > 2.5 Vpp`、削顶、自激或 OTR 立即停止 |
| 放大器加载增益 | 正式带内实测 `Gamp` 约 4.62～4.64；目测约4与50 Ω理论值4.516仅作拓扑线索 | 必须以冻结校准资产覆盖当前正式范围 |
| 增益压缩 | 450 mVpp 历史点已确认压缩并排除 | 当前正式范围只到250 mVpp；若扩量程必须重新标定 |
| 放大器 10～500 kHz 相对增益变化 | 不超过 0.1 dB，补偿后独立点残差尽量不超过 0.5% | 端到端幅值误差必须通过 |
| 输入端等效噪声 | 不超过 0.5 mVrms | 不得造成 5 mV 误差超限 |
| 新增带内固定杂散/互调 | 小于 1 mVpeak 输入端等效值 | 不得把不存在的谱线判成有效分量 |
| THD | 大信号优于 -60 dBc，或不高于 RTM THD 加 0.1 个百分点 | 不能造成谱线/Vpp/RMS 超差 |
| FIR 1 MHz 起阻带 | 衰减下界不小于 50 dB | 第三项恢复结果仍须满足 5 mV |
| 1～10 MHz 干扰 | 衰减下界不小于 50 dB | `u_b` 各项误差不大于 5 mV |
| `>10 MHz` 实验性折叠残余 | 小于 1 mVpeak 输入端等效值 | 不作为本轮长稳前置，但不得写成已全面覆盖 |
| 校准后 Vpp、真 RMS、谱线峰值 | 独立验证点绝对误差尽量不大于 3 mV | 绝对误差不大于 5 mV |
| 基频 | 绝对误差不大于 500 Hz | 绝对误差不大于 1 kHz |
| 数据完整性 | 8192 点/帧、12 包、状态与时间戳一致 | CRC/序号/frame_id/OTR/FIFO/drop/NIC/GEM 错误全零 |
| 前端首帧延迟 | 不超过 250 ms | 完整系统最终不超过 2 s |
| 500 s 增益漂移 | 不超过 0.05 dB | 不得导致赛题指标超差 |

若 DG、RTM 和探头的综合不确定度大于工程 3 mV 目标，就只能判定是否满足 5 mV 底线或给出测量上限，不能报告虚假的小数位精度。

## 11. 执行顺序与停点

1. 离线生成全部正弦/ARB 文件、理论 Vpp/RMS/谱线、折叠频率表和 manifest，并验证哈希。
2. 完成 A、B、C；输入语义、探头修正、噪声或自激未查清前不进入大信号。
3. 完成 D 的低幅阶梯和 250 mVpp 正式点；450/500 mVpp 不属于当前验收，若未来扩量程必须另建受控计划。
4. 完成 E，并冻结第一版端到端校准；用保留频点验证通过后才能进入题目等效多音。
5. 完成 F、G、H；先证明 1～3 MHz 正常，再执行 I 中 4～10 MHz 的正式点。
6. A～I 的 `<=10 MHz` 正式矩阵通过后执行 J 长稳。
7. `>10 MHz` 折叠攻击在时间和仪器条件允许时单独执行，明确标为实验性，不阻塞本轮收口。
8. 最终恢复正式 real-ADC 镜像、DG 安全 OFF 状态和正式单路 5 V供电状态，完成只读复核。
