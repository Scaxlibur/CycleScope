# AD9226 通道 A 与 Zynq-7010 接线定义

## 1. 适用范围

- 更新时间：2026-07-31
- FPGA：Zynq-7010，封装 `xc7z010clg400-1`
- ADC：AD9226 模块，仅使用通道 A
- 原始采样率：65 MSPS
- 通道 B：当前不接入 PL，不定义 FPGA 管脚；后续确有需求时再单独扩展
- 连接方式：不使用旧引脚转接板，AD9226 模块与 Zynq-7010 按第 2 节直接连接

本文冻结 AD9226 通道 A 与 Zynq-7010 的板间接线。工程端口名称以
`Zynq_7010_PL` 当前顶层为准。

## 2. 接线表

| AD9226 模块信号 | 方向 | Zynq-7010 封装脚 | PL 工程端口 | 含义 |
|---|---|---|---|---|
| `ACK` | Zynq → ADC | `H16` | `Adc_Clk_A` | 65 MHz ADC 采样时钟 |
| `A1` | ADC → Zynq | `H17` | `Adc_In_A[0]` | 数据 bit 0，LSB |
| `A2` | ADC → Zynq | `B19` | `Adc_In_A[1]` | 数据 bit 1 |
| `A3` | ADC → Zynq | `A20` | `Adc_In_A[2]` | 数据 bit 2 |
| `A4` | ADC → Zynq | `C20` | `Adc_In_A[3]` | 数据 bit 3 |
| `A5` | ADC → Zynq | `B20` | `Adc_In_A[4]` | 数据 bit 4 |
| `A6` | ADC → Zynq | `D19` | `Adc_In_A[5]` | 数据 bit 5 |
| `A7` | ADC → Zynq | `D20` | `Adc_In_A[6]` | 数据 bit 6 |
| `A8` | ADC → Zynq | `J18` | `Adc_In_A[7]` | 数据 bit 7 |
| `A9` | ADC → Zynq | `H18` | `Adc_In_A[8]` | 数据 bit 8 |
| `A10` | ADC → Zynq | `F19` | `Adc_In_A[9]` | 数据 bit 9 |
| `A11` | ADC → Zynq | `F20` | `Adc_In_A[10]` | 数据 bit 10 |
| `A12` | ADC → Zynq | `G19` | `Adc_In_A[11]` | 数据 bit 11，MSB |
| `ORA` | ADC → Zynq | `G20` | `Otr_A` | 通道 A 超量程指示 |

`ACK` 按现有 PL 端口语义解释为 Zynq 输出给 AD9226 的采样时钟；`ORA`
按 AD9226 通道 A 的 over-range 输出处理。

### 2.1 模块排针的物理布局

厂家手册中的模块接口图显示，通道 A 的 2×排针采用奇偶交错布局，并不是沿
单列按 `A1`、`A2`、`A3`……顺排。以模块元件面朝上、板上
`AD9226_2CH_V1.0` 字样正向、SMA 接口位于右侧观察，通道 A 相关各排为：

| 靠板外侧一列 | 靠板内侧一列 |
|---|---|
| `A1` | `ACK` |
| `A3` | `A2` |
| `A5` | `A4` |
| `A7` | `A6` |
| `A9` | `A8` |
| `A11` | `A10` |
| `ORA` | `A12` |

因此现场复核不能只按“从上到下第几根线”判断，必须同时核对列方向和 PCB 丝印。
尤其注意 `A2/A3`、`A10/A11` 以及相邻的 `A12/ORA`，这些位置最容易因把排针
误认为线性编号而接错。此表只描述模块端观察方向；翻到焊接面或从排针背面观察时，
左右会镜像。

## 3. 数据位序与码型

`AD9226_2CH_V1.0` 模块厂家手册第 5～6 页明确说明 `A1` 为最低位、`A12`
为最高位，第 8 页例程也依次连接 `Adc_In_A[0]`～`Adc_In_A[11]`。因此逻辑
位序冻结为：

```text
A1 = D0 = LSB
...
A12 = D11 = MSB
```

厂家手册第 3、11 页同时明确模块输出格式为直接码（straight/offset binary），
零差分输入的原始码为 `0x800`。第 11 页还说明模块模拟差分前端反相，厂家电压
换算先执行 `D ^ 0xFFF`；这是模拟极性校正，不是把 `D0`～`D11` 首尾反序。

厂家手册只能证明模块端信号的定义，不能证明现场跳线确实逐根接到了本表中的 Zynq
封装脚。首次上板仍须用 raw-IOB 捕获配合已知斜坡核对局部交换、极性和采样相干性；
在此之前不得用整组 bit reverse 掩盖个别跳线错误。手册 OCR 版见
[厂商资料原文](https://github.com/Scaxlibur/CycleScope/blob/main/docs/AD9226_2CH模块使用手册_V1.0/full.md)。

## 4. 对应 XDC 约束

```tcl
set_property PACKAGE_PIN H16 [get_ports Adc_Clk_A]

set_property PACKAGE_PIN H17 [get_ports {Adc_In_A[0]}]
set_property PACKAGE_PIN B19 [get_ports {Adc_In_A[1]}]
set_property PACKAGE_PIN A20 [get_ports {Adc_In_A[2]}]
set_property PACKAGE_PIN C20 [get_ports {Adc_In_A[3]}]
set_property PACKAGE_PIN B20 [get_ports {Adc_In_A[4]}]
set_property PACKAGE_PIN D19 [get_ports {Adc_In_A[5]}]
set_property PACKAGE_PIN D20 [get_ports {Adc_In_A[6]}]
set_property PACKAGE_PIN J18 [get_ports {Adc_In_A[7]}]
set_property PACKAGE_PIN H18 [get_ports {Adc_In_A[8]}]
set_property PACKAGE_PIN F19 [get_ports {Adc_In_A[9]}]
set_property PACKAGE_PIN F20 [get_ports {Adc_In_A[10]}]
set_property PACKAGE_PIN G19 [get_ports {Adc_In_A[11]}]

set_property PACKAGE_PIN G20 [get_ports Otr_A]
```

工程当前采用 `LVCMOS33`。2026-07-31 的 Vivado 2025.1 完整实现确认上述 14 路
均位于 Bank 35，正式镜像全局 setup/hold 为 `+1.916/+0.007 ns`；p210 raw-IOB
镜像的 ADC 输入 setup/hold 为 `+2.401/+7.276 ns`，13 路输入均进入独立 ILOGIC。
DRC、CDC、bus-skew 与含 bitstream XSA 门禁均通过。正式 bitstream SHA-256 为
`cb7c72707a5f79ef61b1b7b324272d825573d911f64a7f1209b0e45984a7a39a`。

这只证明 FPGA 约束与数字实现正确，不能替代 ADC 的电气验收。首次上板仍须确认
`ORA` 未异常置位，并用受控模拟输入复核幅值、极性、逐位位权及采样相干性；`OTR=1`
时不得用收到的 UDP 样点声称模拟链已通过。

同日的新直连接线实测中，p210 raw-IOB 在 `100 kHz / 1.016 Vpp` 下捕获 16,384
点，12 个数据位均同时观察到 0/1，`A8 → J18 → D7` 有 156 次翻转，ORA 全程为
0；正式链 23 帧输出为 `-197..223`、421 个连续码，THD 中位数约 `0.064%`、
SFDR 中位数约 `67.1 dB`。这说明旧转接板造成的 D7 常高与强奇次谐波已经消失；
有限幅度正弦仍不能单独冻结所有高位之间的相对次序，位序最终事实源仍是第 2、3 节。

## 5. 首次上板检查顺序

1. 确认 ADC 与 Zynq 共地，相应 I/O Bank 的 VCCO 与 ADC 数字接口兼容。
2. 先测 `ACK/H16`，确认存在约 65 MHz 时钟。
3. 再观察 `A1`～`A12` 是否随模拟输入变化，检查 `ORA/G20` 是否异常常高。
4. 禁用 PL 内部测试图样后读取 raw-IOB 与真实 ADC 帧，核对 `0x800` 零点、
   正负极性、逐位位权和跨码单调性。
5. 无数据时依次排查采样时钟、ADC 供电/使能、数据位序和 XDC；不要先怀疑 UDP。
