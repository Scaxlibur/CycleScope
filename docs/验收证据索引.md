# CycleScope 合并前验收证据索引

> 更新：2026-08-02
> 作用：为合并、答辩和后续复现提供一份可追溯目录；不复制或改写任何已哈希的原始证据。

## 1. 使用规则

1. 本文件和 `public/测试与证据索引.md` 是受版本控制的导航入口；原始 `pcap`、`npy`、S16 帧、仪器导出和构建二进制留在 `tool-of-rei/evidence/` 的忽略档案中。
2. 已完成的证据根不能改名、移动或编辑；需要补充说明时，只在本索引、根 README 或新的独立包中增加材料。
3. 每次离线备份必须保留目录层级、根 `SHA256SUMS` 和本索引。进入一个证据根后执行 `sha256sum -c SHA256SUMS`；没有清单的历史包只能作为辅助材料。
4. “PASS”只表示该包声明并通过的范围，不自动覆盖另一校准身份或未复验的源码。FPGA 的唯一最终基线为 `fpga-v1.0.0@038e981`。

## 6. 数据类型、内容与备份

| 类型 | 常见内容 | 处理原则 |
|---|---|---|
| `pcap`、`tcpdump.log` | UDP checksum、分片、网卡丢包和时间序 | 原样保留，不能用摘要代替。 |
| `*.npy`、`*.s16le`、帧 JSON | 示波器原始波形、FPGA码序列、P4重组帧 | 原样保留；只读重分析，禁止重采后覆盖。 |
| `summary.json`、`manifest.json`、`report.json` | 结论、输入、版本、SHA和门限 | 作为快速审查入口；与同根 `SHA256SUMS` 一起备份。 |
| `.bit/.xsa/.elf/.bin` | 可下载构建产物 | 必须附提交身份和 SHA；FPGA 正式产物只认 `fpga-v1.0.0@038e981` 及其 M14 固化链。 |
| 仪器命令/状态日志 | DG4202、RTM2032、DP832、JTAG 安全与恢复 | 原样保留，尤其是失败/输出 OFF 记录。 |

当前 `tool-of-rei/evidence` 与 `source_data_for_test` 均由 `.gitignore` 排除。合并前应做一次只读外部归档，至少记录归档媒介、日期和顶层 SHA；不要在清理磁盘时删除 `source_data` 与点级 `evidence` 中看似重复的原始数据，它们服务不同的可追溯链。
