# CycleScope 文档索引

`docs/` 是项目文档的唯一常规入口：协议、接线、标定、联调、测试计划和交接说明都在此维护；赛题原件、厂商资料与历史设计稿也原样保留在本目录。

## 当前结论与边界（2026-08-02）

- 正式普通输入范围冻结为不超过 `250 mVpp`；450 mVpp 压缩点是历史负证据，不参与当前拟合、验证或验收。
- P4 逐频响应资产为 `C5DCDE41`，上游校准身份为 `25030 / 516 µV/code / -6761 µV`。
- 完整 M8/M9 20 例审计绑定应用 BIN `d819641d…d8207007`；后续 F0 两位小数构建 `e30d16c4…a4bac0e` 只完成构建、烧录和 100 帧链路烟测，不能混作同一发布身份。
- `source_data_for_test/` 当前有 124 个真实 FPGA 回放点；其 manifest、pcap 与 SHA256SUMS 已按历史哈希精确恢复。该目录和原始 evidence 都是本机/外部归档，不随普通 Git clone 携带。

## 口径规则

1. 对同一结论，以日期更晚且带证据根、SHA256 和适用范围的记录为准。
2. 已哈希原始证据只能原位保存；补充说明写入索引或新的独立证据包，不能回写历史 JSON、日志、pcap、波形或镜像。
3. 历史计划、旧工作树、早期电脑模拟器和设计初稿只能解释过程；当前结论以本目录的测试/验收索引和 `final_doc/` 为准。
