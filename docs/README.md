# docs 资料索引

这里保存赛题原件、主办方答疑、厂商参考资料和历史设计材料。它们是设计与验收的背景依据，不等同于当前构建的最终运行证据。

| 分类 | 内容 | 使用方式 |
|---|---|---|
| 赛题原件 | G题_周期信号测量分析装置/ 下的 PDF、结构化导出和全文 | 需求、指标与措辞的原始依据。 |
| 主办方答疑 | 主办方答疑/ 下的原始文本 | 与赛题一起阅读；带 (1) 的副本保留原样，不以文件名推断优先级。 |
| ESP32-P4 参考 | ESP32-P4-Function-EV-Board… 目录 | 板级接口、显示与以太网资料。 |
| FPGA 参考 | Z7-Nano 用户手册… 目录 | Zynq-7010 板级资料。 |
| 历史设计报告 | G题_周期信号测量分析装置/CycleScope设计报告初稿.md | 设计过程稿；其中“待实物验证”条目不能替代后续测量结论。 |
| 验收证据索引 | 验收证据索引.md | 证据根、哈希与正式性边界；与 public/测试与证据索引.md 互相链接。 |
| FPGA 验收证据索引 | FPGA验收证据索引.md | FPGA 冻结基线、M8/M10/M11/M12/M14 和本地原始档案位置。 |

可提交的最终报告稿件位于仓库根目录的 final_doc/。原始仪器数据与运行日志不复制到这里，而是在 tool-of-rei/evidence/ 中以外部归档方式保存。
