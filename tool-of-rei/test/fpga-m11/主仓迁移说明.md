# FPGA M11 夹具主仓迁移说明

本目录是从 CycleScope-FPGA 的 tool-of-rei/m11/ 机械导入的源码归档，来源基线为 codex/FPGA 的 fpga-v1.0.0@038e981。导入范围仅包括 Python、Tcl、TOML 和 Markdown 源文件；没有导入 __pycache__、构建物、原始波形、pcap 或仪器私有配置。

## 内容

- m11_*.py：M11 现场 runner、WaveBench 安全封装、离线汇总与长稳分析。
- test_m11_*.py：相应的主机单测。
- plans/：只读预检和信号源安全 OFF 的计划样例。
- README.md、M11-A现场确认.md：原始操作说明和现场历史。

## 使用边界

这些文件不是一组可直接批量执行的普通单测。部分 runner 会打开 WaveBench、读取真实归档或操作现场仪器；运行前必须阅读原 README、参数和数据根。当前主仓内的原始 FPGA 证据位于 tool-of-rei/evidence/，124 个回放点位于 source_data_for_test/，二者均保持 Git 忽略。

若仅需了解 FPGA 最终证据与基线，请先看 ../../fpga-history/README.md 和 ../../../docs/FPGA验收证据索引.md。

## 历史复现边界

本目录保留的是原始源码，不是一次重新生成 M11 结论的授权。原 runner 假定
`CycleScope-FPGA/tool-of-rei/m11/` 的目录层级、`codex/FPGA` 分支守卫和未提交的
`tool-of-rei/private/m8-wavebench-safe.toml`；私有仪器配置不随主仓迁移。

此外，M11 的 `matrix-v1`～`matrix-v3` 固定绑定已不在当前工作树中的历史事实源
`public/信号前端测量方案.md`，其 SHA-256 为
`9ef0a78474523dc6c110dc6880202b1431be81abc08a33b0ff23164639370070`。当前
`public/系统补偿方案/信号前端测量方案.md` 是后续修订版，不能替换它来重写历史矩阵。
所以本目录下的单测或 runner 在主仓直接运行时可能因上述前置条件 fail-closed；定量结论
应复核原始 evidence 及其 `SHA256SUMS`，而不是以一次无法满足历史输入的重跑替代证据。
