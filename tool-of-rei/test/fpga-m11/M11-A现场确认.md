# M11-A 现场确认清单

## 已由用户确认

- DG4202 CH1、放大器输入、RTM2032 CH1 位于同一电气网络。
- 放大器加载输出、AD9226输入、RTM2032 CH2位于同一电气网络。
- DG4202 CH1固定50 Ω负载语义；放大器输入按50 Ω设计。
- RTM2032 CH1/CH2始终高阻，不允许切换为50 Ω。
- DP832是唯一外部电源，所有设置、保护和输出控制永久禁止自动写入。

- [x] AD8065反馈取样在串联电阻前/后不纳入本轮门禁；不报告`Gfb/Kmatch`，只直接
  测量CH1输入、CH2 ADC节点和LAN数据。
- [x] `RF`由用户明确确认采用名义`1608 Ω`；不冒充万用表实测。
- [x] `RG`由用户明确确认采用名义`200.2 Ω`；不冒充万用表实测。
- [x] 输出串联电阻由用户明确确认采用名义`50 Ω`；不冒充万用表实测。
- [x] RTM CH1/CH2均保持高阻并手动改为`DCL`，用于正式DC偏置/噪声证据；禁止选
  `DC`，后者在RTM语义中可能是50 Ω。
- [x] 用户确认CH1/CH2探头和RTM菜单倍率均按`1×`读数，不做探头交换修正。
- [x] 内部正负电源轨和器件温度不作为本轮自动测试前置条件；不得宣称已完成这些
  表征。DP832仍永久只读。
