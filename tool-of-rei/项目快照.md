## 冻结硬件与软件基线
- ESP32-P4 Function EV Board revision v1.0，CPU 360 MHz，16 MB Flash，32 MB PSRAM。
- 1024×600 MIPI-DSI、EK79007、GT911；LVGL 9.4.0、`esp_lvgl_adapter` 0.6.2、BSP 5.2.3。
- `esp_codec_dev` 固定 1.5.10，避免 1.5.11 发布包的 CMake 错误。
- ADC：单颗 AD9226 通道 A，原始 65 MSPS；不采用双 ADC 130 MSPS 交织。
- 网络：P4 `192.168.10.3:50001`，生产 FPGA `192.168.10.2:50000`，静态 IPv4/UDP，无网关和 DHCP。
- 物理链路按 P4 百兆口设计；默认两板普通网线直连，交换机用于联调和抓包。

## 冻结 Profile 1 与 CSLP
- FPGA 先低通并 16 倍抽取，线上样点率 4,062,500 S/s。
- 每帧 8192 个 S16_LE 样点，采集窗约 2.016 ms，FFT 栅格约 495.910645 Hz。
- 异步投递周期 50 ms（20 frame/s）；WAVE_DATA 应用头 72 字节，每帧固定 12 个 UDP 包。
- 控制面使用应用层 ACK、100 ms 超时、最多 3 次重试和同序号幂等缓存。
- 数据面无 FRAME_ACK、重传或背压；坏包/缺片丢整帧并保留上一有效结果。
- 三缓冲角色为 assembling/latest/in_use；未采用的 latest 可覆盖，InUse 绝不覆盖。
- 消费 API：`acquire_latest(FrameCursor{session_id, frame_id})` → 处理 → `frame_is_current()` → 发布 → `release()`。

## 组合架构

```text
CSLP receiver（Core 1，priority 6）
  → assembling/latest/in_use 三缓冲
  → [待接入] 唯一正式 mailbox consumer

本地 S16 合成帧（Core 1，priority 5）
  → esp-dsp 8192 点 FFT/测量（Core 1，priority 4）
  → 4097 Bin PSRAM A/B
  → 640 列 peak/RMS + 深度 1 latest 结果队列
  → LVGL worker/UI（Core 0）
```

- LiveDataPipeline 用 Core 1、priority 5 的本地 S16 合成帧驱动真实 esp-dsp FFT8192，再由 priority 4 analysis 处理。

- 网络 receiver priority 6 高于模拟/未来 capture priority 5 和 analysis priority 4，保持收包可抢占计算。
- LVGL API 只能在 Core 0/UI 上下文调用；网络和分析任务不得持有 LVGL 对象。

## 已完成的显示链
- 时域：每个显示像素列保存源区间 min/max，1P/3P 包络不会吞峰。
- 频域：完整 4097 个正频率 Bin 保留在 Core 1 的两个 32,784-byte PSRAM 缓冲中轮换。
- 显示压缩：4097 Bin → 640 列，每列保留 peak 与 RMS；最多附带 16 个语义峰值。

- 实机 20 Hz 压力：`rx=573, analyzed=573, published=573, ui=571, dropped=0, max_ui_gap=58 ms`。

## 已完成的 FFT 处理链
- `FftProcessor8192` 使用 `espressif/esp-dsp` 的 8192 点 FC32 FFT；编译时强制优化实现，map 已确认链接 ESP32-P4 `dsps_fft2r_fc32_arp4_`。
- 对 S16 采样执行物理量标定、去直流、Hann 窗、FFT/位反转和单边幅度校正，输出 4097 个 0…Fs/2 Bin。
- 测量输出包含 Vpp、真有效值、基频和三条精确谱线；自检向量为非相干 40.75 kHz 基频及 3/4 次谐波。
- 4097 点单边谱压缩为 640 列 peak/RMS，保留每列峰值；三条精确谱线填入全频谱峰值结构。
- FFT 大缓冲、窗、旋转因子表和单边谱优先放入 PSRAM；任务栈使用内部 RAM。
- `tools/generate_fft_test_vector.py` 可生成/校验与固件一致的 8192 点 S16 合成数据。
