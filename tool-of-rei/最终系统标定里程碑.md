## 3. 已冻结的接线与豁免项

### 3.1 接线

```text
DG4202 CH1 ─── AD8065 放大器输入

RTM2032 CH1：后续正式验收未接入，输入真值直接使用DG 50 Ω设置

AD8065输出 ─┬─ RTM2032 CH2
            └─ AD9226输入 → FPGA → P4

FPGA CSLP主发：192.168.10.2 → P4 192.168.10.3:50001
```

历史双通道分层点要求RTM CH1、CH2来自同一次 acquisition；后续CH1未接入的正式点只采CH2。电脑镜像接收器不得发送任何网络报文，也不得建立第二个 CSLP session。

### 3.2 用户明确不要求复核的项目

以下事项只在证据清单中记录为“用户授权固定条件”，不作为前置检查、失败项或停机原因：

- AD8065反馈取样在50 Ω串联电阻前还是后；
- CH1/CH2探头倍率与RTM菜单倍率均按1处理，不做探头交换修正；
- 内部正负电源轨和器件温度。

仍保留与防止过驱直接相关的安全门槛，因为这不是标定洁癖，而是避免真的把硬件顶坏。

## 4. 标定数据模型

所有正弦幅值统一使用单边峰值。对RTM和FPGA原始样本去直流后，在已知刺激频率上使用正弦最小二乘或相干投影；示波器原始最大值减最小值只作为削顶观察，不进入正式增益拟合。

```text
Aset = DG 50 Ω设置Vpp / 2
A1   = RTM CH1基波峰值
A2   = RTM CH2基波峰值
Cpk  = FPGA帧基波code peak

Ksrc(f,A) = A1 / Aset
Gamp(f,A) = A2 / A1
Kadc(f,A) = Cpk / A2
Sset(f,A) = Aset × 1e6 / Cpk       [µV/code]
Sch1(f,A) = A1   × 1e6 / Cpk       [µV/code]
φamp(f,A) = wrap(φCH2 - φCH1)      [degree]
```

正式 P4 补偿使用 `Sset(f)`；其他量只用于定位误差和形成不确定度报告。`φamp` 本轮记录但默认不上线，不能把它冒充 DG→FPGA 绝对相位。

## 13. M7：ESP32-P4本地逐频补偿实现

### 补偿位置

P4保持当前处理顺序：

```text
code → 上游516 µV/code标量 → 去直流 → FFT → 峰选择
→ 频率精修 → project_at_frequency()
→ P4逐频幅值补偿
→ 谱线/RMS/Vpp/1P/3P/频谱显示
```

对每条确认的有效带谱线：

```text
K(f) = Snew(f) / incoming_scale_uV_per_lsb
Acorrected(f) = Ascalar(f) × K(f)
```

### 必须保持的行为

- 峰检测、候选排序和SNR门槛继续使用补偿前标量数据；
- 正式谱线与显示谱线使用校正后的峰值；
- `RMS = sqrt(sum(Acorrected_i² / 2))`；
- Vpp和1P/3P使用校正幅值与当前测得相位重构；
- 频谱图在10～500 kHz内使用同一插值，带外保持未补偿诊断值；
- 不改变FPGA、CSLP字段、接收状态机、采集门槛或频率精修算法。

### Fail-closed身份门禁

只有上游六项身份全部精确匹配时启用P4表。任何一项变化：

- 不套用旧表；
- 记录明确的profile mismatch；
- 不把未校准值标成已补偿结果；
- 不影响网络连接状态卡对链路/有效帧的既有判断。

### 验证
