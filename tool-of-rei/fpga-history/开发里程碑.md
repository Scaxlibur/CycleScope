# FPGA 开发里程碑与最终冻结

## 最终架构

```text
AD9226 通道 A @ 65 MSPS
  → 低通 + 16 倍抽取 @ 4.0625 MS/s
  → 8192 点 S16 双 bank
  → AXI-Stream → S2MM DMA → PS → CSLP/UDP over LAN
```

唯一最终版本为签名 tag `fpga-v1.0.0@038e981`。固定线上 Profile 为 8192 点、50 ms、12 个 WAVE 分片；P4 是唯一控制端，电脑只可作为被动镜像接收者。

## 发布纪律

1. 不修改 `038e981` 的源码、构建身份或已哈希原始证据。
2. 任何后续设计改动必须使用新版本名、新 bit/XSA/ELF、明确的校准身份和独立验收根。
3. 合并时提交共享索引和必要源码；大型原始数据维持外部/本地只读归档，并随根 `SHA256SUMS` 备份。
