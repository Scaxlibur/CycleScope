# M11 AD8065 前端—AD9226—FIR—LAN 全链路验收计划

## 1. 目标与事实源

M11 验收以下真实链路：

```text
DG4202 CH1
  → 装置 BNC / AD8065 同相放大器输入
  → AD8065（RF=1.608 kΩ、RG=200.2 Ω，反馈增益 9.031968032 V/V）
  → 约 50 Ω输出串联匹配（精确匹配时负载端理论增益 4.515984016 V/V）
  → AD9226 通道 A（ADC 是放大器输出端唯一正式 50 Ω负载）
  → FPGA 65 MSPS → 三级 FIR → /16
  → 4.0625 MS/s、8192×S16_LE
  → DMA / Zynq PS / CSLP-UDP / 电脑
```

正式需求和测量口径以根目录
`public/信号前端测量方案.md` 为事实源；本文件只把它整理成可恢复、可执行、可停点的
里程碑清单。本次同步的事实源为 475 行，SHA-256：
`9ef0a78474523dc6c110dc6880202b1431be81abc08a33b0ff23164639370070`。

- 本轮不验收 ESP32-P4、LVGL 或 SPI。
- 不写 QSPI，不访问或脉冲 MIO47。
- 正式板级数据只从 LAN 获取；内部 test pattern 只能辅助分层诊断，不能替代真实输入。
- M11 包含前端与整链校准，不再把绝对幅值校准顺延到另一个里程碑。

## 3. 正式接线与三层事实

```text
DG4202 CH1（50 Ω显示/负载语义、0 V offset）
    │
    └── 装置 BNC / AD8065 IN
          └── RTM2032 CH1：高阻、DC 耦合，测 Vin

AD8065 OUT ── 输出串联匹配 ── AD9226 A 输入（ADC 自身为唯一 50 Ω负载）
          └── RTM2032 CH2：高阻、DC 耦合，测 Vadc

AD9226 A → FPGA FIR/抽取 → LAN → 电脑帧
```

RTM CH1、CH2 必须来自同一次 acquisition。每条谱线同时记录：

```text
源/输入层：DG 设置值、CH1 实测值、Ksrc = Vin / Vset
模拟层：  CH2 实测值、Gfb、Kmatch、Gamp = CH2 / CH1、相位、噪声和失真
数字层：  FPGA code、Kadc = code / CH2、FIR 衰减和帧状态
整链层：  Ke2e = code / DG 设置值
```

这样才能把输入加载、放大器、ADC/FIR和端到端校准分开判责。DG 设置值仍是赛题幅值基准；
CH1/CH2 用于归因，不能把一个相对 DG 设置值超差的结果重新定义成通过。

## 4. 量程预算与安全硬门槛

按反馈电阻和精确 `50 Ω + 50 Ω` 匹配得到的理论预算：

| DG/装置输入 | 用途 | 理想 ADC 节点 |
|---:|---|---:|
| 10 mVpp | 5 mVpeak 最小谱线单音检查 | 45.16 mVpp |
| 50 mVpp | `u_b` 整体下边界 | 225.80 mVpp |
| 100 mVpp | `u_a` 整体下边界 | 451.60 mVpp |
| 200 mVpp | 正式干扰 `u_J` | 0.9032 Vpp |
| 250 mVpp | `u_a/u_b` 整体上边界 | 1.1290 Vpp |
| 450 mVpp | `250 mVpp u_b + 200 mVpp u_J` 保守压力 | 2.0322 Vpp |
| 500 mVpp | 非赛题余量点 | 2.2580 Vpp |

当前“约 4 倍”仅为用户观察示波器后的粗略估算，不是正式测量，也不得用于生成
`scale_uV_per_lsb`。理论输入等效比例约为 `0.540614458 mV/code`；若定量测量最终确为
4 倍，则约为 `0.610351562 mV/code`。正式值只能由端到端校准冻结。

名义值和目测值都不能代替分层实测。安全门槛如下：

1. DG CH1 固定 50 Ω语义、0 V offset，burst/modulation/sweep 关闭；改变函数、频率、
   幅值或 ARB 前必须先输出 OFF。
2. M11 私有 WaveBench 配置必须把 `max_source_vpp` 收紧为 `0.5 Vpp`；仓库默认
   `5.0 Vpp` 和直驱 ADC 私有配置的 `2.0 Vpp` 均不允许用于本计划。DG 命令不得超过
   500 mVpp，CH1 实测不得超过 550 mVpp。
3. CH2 正常目标不超过 2.35 Vpp；`Vadc > 2.5 Vpp`、异常直流偏置、削顶、持续振铃、
   自激或 ADC OTR 任一出现，立即 DG OFF 并停止 campaign。
4. 首点从 `100 kHz / 10～50 mVpp` 开始，按幅度单调上升；450/500 mVpp 最后执行。
5. `Ksrc` 未冻结前不得假设 DG 设定值等于放大器真实输入。若输入近似高阻导致 CH1
   接近 DG 设置值的 2 倍，按 CH1/CH2 硬门槛停机，不为完成矩阵强行升幅。
6. RTM CH1、CH2 都必须为高阻。CH2 误设 50 Ω会与 ADC 并联成约 25 Ω，该点直接作废。
7. 正式供电只允许装置的一路 5 V 外部输入，正负运放电源由装置内部变换。台式双电源
   预调试结果不得冒充正式供电合规证据。
8. 所有仪器、ADC、FPGA和放大器共信号地；示波器地夹严禁接内部负电源轨。
9. DP832 是整链唯一外部电源，只允许读取身份、状态、电压/电流和保护状态；M11
   自动化不得包含 `power.set`、`power.output` 或保护参数写入，也不得改变输出状态。
10. 有意合成的多音/谐波和核心阻带矩阵最高为 3 MHz；`4/5/7.2/7.5/10 MHz` 是本轮
    **正式单频干扰覆盖**，不是可跳过的实验扩展。`>10 MHz` 不进入本轮自动计划。
11. 任一点出现供电过流、异常升温、FPGA/FIFO overflow、frame drop、码异常跳变或
    仪器恢复歧义，保存失败证据、保持 DG OFF，不自动重试。
12. 最终固定恢复为 `SIN / 100 kHz / 50 mVpp / 50 Ω / 0 V offset / OFF` 并回读；
    DP832 仅记录终态，不由自动化“恢复”或重写。

## 5. 每个测试点的统一闭环

每个正式点必须依次完成：

1. 记录 DG、RTM、DP832 身份与初态；回读 DG profile、RTM CH1/CH2 高阻状态以及
   DP832 电压/电流/保护状态，电源全程只读。
2. DG OFF 下设置函数、频率、幅值或 ARB；保存设置、谱线 manifest 和 SHA-256。
3. 显式 DG ON，等待至少 1 秒或已验证的稳定时间。
4. RTM 一次 acquisition 同时保存 CH1、CH2 的 NPY/CSV/metadata/commands.log；需要时
   保存截图，但截图不能替代原始波形。
5. 保存与 DG ON 时间窗相交的至少 22 个完整 LAN 帧；边界、最小谱线、组合输入和
   10 MHz 点至少 64 帧。
6. 显式 DG OFF 并回读真实终态。
7. 生成 CH1、CH2、FPGA 三层分析、协议完整性、不确定度和 PASS/FAIL。

WaveBench run-plan 当前只门禁一个 `scope_guard_channel`，因此不能单独充当 M11 的
双通道证据。M11-0 必须建立以下组合事务：先分别只读门禁 CH1/CH2 高阻，由 checked
source plan 管理 DG 的 `OFF → 配置 → ON → OFF` 窗口，在 ON 窗口内用一次
`scope capture --channel 1 --channel 2` acquisition 保存两通道，并并行捕获 LAN。
事务前仍固定执行 `run check → run verify → run plan`；任何能力、状态或时间窗门禁失败
都 fail closed。刺激窗口、RTM acquisition 和 LAN 帧时间线不相交时整点作废，不挑选
“看起来正常”的帧。

## 6. A～J 实测矩阵

### A. 物理、探头和供电预检

- 断电测量放大器输入阻抗、ADC 输入阻抗和地连续性。
- 断电复核 AD8065 同相拓扑及反馈取样在匹配电阻前/后的真实节点，实测 `RF/RG` 和输出串联电阻；与
  `1.608 kΩ/200.2 Ω/目标 50 Ω` 不符时重算反馈增益和分压。
- CH1、CH2 探头同时接真实 50 Ω终端，在 `10 kHz / 500 kHz / 3 MHz` 比对幅相并交换
  探头复测，冻结通道修正量。
- 使用装置单路 5 V 输入，记录冷机/热机电流、内部电源轨、放大器输出 DC 和温度。
- DG OFF 时检查 CH2 全带宽振荡和固定杂散。
- ADC 50 Ω保持连接，以 `100 kHz / 50 mVpp` 小信号带限阶跃/方波先测 AD8065 输出引脚、
  再测 ADC 节点，检查过冲、振铃与匹配分压；持续振荡直接停机，过冲大于 10% 时先
  排查 `RF=1.608 kΩ`、输出匹配、电容负载和布局。

验收：接线、双通道修正、供电和稳定性全部可解释，才进入 B。

### B. 零输入、噪声和偏置

DG 连接但保持 OFF，保存同窗 CH1/CH2 和至少 64 个 FPGA 帧：

- CH1/CH2：DC、RMS、Vpp、0～500 kHz 积分噪声和最大离散杂散；
- FPGA：均值、AC RMS、码范围、固定谱线、离群点率和 OTR；
- 计算 CH2/实测增益与 FPGA/整链折回装置输入端的等效噪声。

目标：输入端等效噪声 `≤0.5 mVrms`，带内固定杂散尽量 `<1 mVpeak`。仪器噪声底不足时
只报告上限，不写成零。

### C. DG 设置值与真实输入关系

- `100 kHz`：DG 设置 `20 / 50 / 100 mVpp`；
- `10 kHz / 500 kHz / 3 MHz`：DG 设置 `100 mVpp`。

计算 `Ksrc = CH1/Vset`。由于 RTM2032 只有两通道，在 `100 kHz / 50 mVpp` 以及
`500 kHz / 3 MHz` 代表点保持 CH1 测 Vin，分两次稳定刺激采集：CH2 先测 AD8065 输出
引脚得到 `Gfb`，再返回 ADC 节点得到 `Gamp`；只有两次 CH1 幅值一致性通过后才计算
`Kmatch = Gamp/Gfb`。示波器目测约 4 倍仅作排查线索，不得进入校准。

### D. 加载增益、线性和动态范围

频率：`10 / 100 / 200 / 500 kHz`。

每个频率按 `10 / 50 / 100 / 250 / 450 / 500 mVpp` 单调升幅，正式同窗计算
`Gamp / Kadc / Ke2e`，并记录压缩、DC、THD、SFDR、二/三次谐波、码域、离群点和 OTR；
`Gfb/Kmatch` 只在 C 的代表诊断点或明确安排的复测点计算。

- 450/500 mVpp 最后执行；
- 450/500 mVpp 还需热机和最低预期单路 5 V输入复测；
- 任一幅值失败，不继续同频率更高幅值。

2026-07-31实测执行决策：首个`10 kHz / 500 mVpp`非赛题余量点的CH1/CH2原始跨度
为`0.580/2.400 Vpp`，超过`0.55/2.35 Vpp`正常门但未越2.5 V立即停机线，因此该点
保留为FAIL，后续频率不重复500 mV。D/E及后续组合刺激live上限冻结为0.45 Vpp；
原矩阵中的500 mV case仅用于绑定此失败证据，不再表示待执行动作。

### E. 10～500 kHz 幅相与第一版校准

训练扫频使用 `100 mVpp`，升频和降频各一轮：

```text
10 / 10.5 / 20 / 50 / 100 / 200 / 300 / 400 /
450 / 475 / 490 / 500 kHz
```

追加：

- `10 / 100 / 500 kHz × 10 mVpp` 最小谱线；
- `10 / 200 / 500 kHz × 50 / 250 / 450 mVpp` 幅频交叉点。

拟合端到端幅相校准后，只用保留点独立验证：

```text
15 / 75 / 150 / 250 / 350 / 425 / 485 kHz
```

校准必须使用多幅度点和非零 `calibration_id`；不得逆补偿 1 MHz 以上阻带。

### F. 1～3 MHz FIR 阻带

正式输入为装置 BNC/DG 设置 `u_J = 200 mVpp` 单音：

```text
1.0 / 1.05 / 1.1 / 1.25 / 1.5 / 1.75 / 1.9 /
2.0 / 2.00625 / 2.05625 / 2.1 / 2.25 / 2.5 / 2.75 / 3.0 MHz
```

再从 Q1.17 FIR 的 1～3 MHz 密集响应中自动选择残余最大的 8 个非重复点。按抽取后
折叠频率做正弦最小二乘/相干投影，以 `CH2 → FPGA` 计算衰减下界，目标 `≥50 dB`。
低于噪声底时必须给出 p95/置信区间下界，不写“无限 dB”。

### G. 题目第 1、2 项多音矩阵

所有分量保持严格谐波关系、频率为 500 Hz 整数倍，有意合成的最高谐波不超过 3 MHz。
每个 ARB 保存各谱线频率、peak、相位、整体 Vpp、真 RMS 和 crest factor。

| 用例 | 整体 DG 设置 | 频率构成 | 重点 |
|---|---:|---|---|
| A-low | 100 mVpp | 10 kHz 基波＋不超过 200 kHz 的 1～2 条谐波 | `u_a` 下边界 |
| A-edge | 250 mVpp | 40 / 120 / 200 kHz | `u_a` 上边界 |
| B-low | 50 mVpp | 10～500 kHz 内基波＋1～2 条谐波 | `u_b` 最低整体码程 |
| B-edge | 250 mVpp | 100 / 300 / 500 kHz | `u_b` 上边界 |
| weak-line | 50～250 mVpp | 至少一条 5 mVpeak，且基波不是最大分量 | 最小谱线识别 |

每例至少一组高 crest factor 和一组低 crest factor。FPGA 离线恢复整体 Vpp、真 RMS、
基频和全部正频率谱线；不能假设最大 bin 就是基波。

### H. 题目第 3 项组合输入

从 G 的 B-low、B-edge、weak-line 各选一组 `u_b`，叠加 `200 mVpp` 单频干扰：

```text
fJ = 1.0 / 1.5 / 2.0 / 2.5 / 3.0 MHz
```

优先使用 DG CH1 单通道 ARB。manifest 分别记录 `u_b`、`u_J`，不得用总 Vpp 代替
干扰定义。检查 CH2 削顶/压缩、FPGA 干扰抑制、带内互调，以及恢复后 `u_b` 的 Vpp、
真 RMS、基频和谱线误差。接近 450 mVpp 的高 crest factor 点至少 64 帧。

### I. 10 MHz 正式上限与 `>10 MHz` 实验边界

本阶段是 M11 的正式覆盖，不是可选扩展。为遵守“多音最高谐波 3 MHz”的操作边界，
只使用单频正弦，不生成高频多谐波波形：

```text
4 / 5 / 7.2 / 7.5 / 10 MHz，DG 设置 200 mVpp
```

每点保存 CH1、CH2、FPGA并计算实际折叠频率下的 `CH2 → FPGA` 衰减；正式目标为
衰减下界 `≥50 dB`。5 MHz、10 MHz 各与一组 B-edge `u_b` 组合复测，校准后恢复的
`u_b` Vpp、真 RMS 和各谱线峰值误差均须 `≤5 mV`；10 MHz 点和两组组合点至少 64 帧。

`>10 MHz` 不进入 M11 自动矩阵，也不作为长稳或本轮收口的前置条件。若用户后续再次
授权，可按独立实验性计划从 `200 mVpp` 或更低的单频正弦开始，优先检查
`n×65 MHz` 及其 `±10/100/250/500 kHz` 邻域；每点仍须同时保存 CH1、CH2 和 FPGA，
并区分信号源/探头带宽、AD8065 模拟滚降和 ADC 前折叠。折叠残余若大于
`1 mVpeak` 输入端等效值，记录为需增加模拟抗混叠措施的风险。不得把有限实验点写成
已经穷尽所有高频干扰。

### J. 响应时间、热机和长稳

- `ENABLE_STREAM` 到首个完整有效帧目标 `≤250 ms`，给整机 2 秒预算留余量。
- 选择 `250 mVpp u_b + 200 mVpp u_J` 中 crest factor 安全且最恶劣的一组，运行
  `10,001` 帧，约 500 秒。
- 首、中、末复测 CH1/CH2、供电电流和温度；每 1000 帧计算端到端增益。
- 保存 pcap、NIC/GEM 统计；CRC、序号、frame_id、时间戳、OTR、FIFO、drop、socket、
  NIC 与 GEM 错误全部要求为零。
- 标称单路 `5.00 V` 完成后，由现场人工确认最低预期外部供电点，再复测 450/500 mVpp
  和 500 kHz/10 MHz 边界；自动化仍只读 DP832，不改变其设置或输出状态。

## 7. 分析、校准与机器可读产物

### 7.1 固定分析口径

- FPGA 输出采样率固定为 `4,062,500 sample/s`，8192 点频点间隔为
  `495.9106445 Hz`，满足 FFT 栅格不大于 500 Hz。
- 单条谱线统一报告单边谱正弦 `peak`；非相干采样补偿窗函数相干增益和单边谱两倍系数。
- 小残余、阻带和互调优先使用正弦最小二乘或相干投影，并按实际抽取后折叠频率求值。
- 真 RMS 按校准后全序列 `sqrt(mean(x^2))` 计算；基波不保证是最大谱线，算法不得把
  最大 bin 自动当作基波。
- 孤立离群点可在稳健拟合中降权，但原始帧、样点位置、离群率和未修复指标必须保留；
  不允许先删点再把结果标成“原始测量”。

### 7.2 校准冻结门

1. B 阶段零输入生成 `offset_code`。
2. 使用 50/250/450 mVpp 多幅度点求线性增益，不能用单点标定覆盖全量程。
3. 使用 E 的训练频点生成 10～500 kHz 平滑幅相校准表。
4. 只用 E 的保留频点和 G/H 多音用例独立验证，不拿训练数据自证。
5. 校准不得逆补偿 1 MHz 以上阻带或高频混叠残余。
6. 前端、电阻、ADC 通道、FIR、探头/负载拓扑或校准表任一改变，必须生成新的非零
   `calibration_id`；旧 LMH6609 和直驱 ADC 标定全部禁止复用。

至少生成 `calibration.json`、`response.csv`、`uncertainty.json` 和 holdout 报告；正式
误差一律相对 DG 50 Ω设置值计算，CH1/CH2 只用于归因和不确定度，不得重定义通过条件。

## 8. 硬验收门槛

| 类别 | 门槛 |
|---|---|
| 负载/安全 | RTM CH1/CH2 高阻；`Vin≤0.55 Vpp`、`Vadc≤2.35 Vpp`；`Vadc>2.5 Vpp`、削顶、自激或 OTR 立即停止 |
| 供电 | 正式证据使用装置单路 5 V 外部输入；内部电源轨、电流和温度可解释 |
| 放大器 | AD8065 反馈理论 9.032、50 Ω加载理论 4.516；目测约 4 不作门槛，定量 `Gfb/Kmatch/Gamp` 稳定可解释；450/500 mVpp 增益压缩工程目标 `≤0.5%`、底线 `≤1%` |
| 幅频 | 放大器 10～500 kHz 相对增益变化工程目标 `≤0.1 dB`；独立保留点通过端到端误差门槛 |
| 噪声/杂散 | 输入等效噪声 `≤0.5 mVrms`；新增带内杂散/互调 `<1 mVpeak` 输入等效值 |
| 失真 | 大信号 THD 工程目标优于 `-60 dBc`，或不高于 RTM 输入 THD 加 0.1 个百分点；不得造成幅值/RMS/谱线超差 |
| FIR | 1 MHz 起全部正式阻带点的衰减下界 `≥50 dB` |
| 1～10 MHz正式干扰 | 4/5/7.2/7.5/10 MHz不得省略；衰减下界 `≥50 dB`，5/10 MHz组合恢复误差 `≤5 mV` |
| `>10 MHz`实验折叠 | 不属于 M11 完成条件；若另行授权，输入端等效折叠残余目标 `<1 mVpeak`，不得声称穷尽所有干扰 |
| 幅值 | 校准后 Vpp、真 RMS、每条谱线峰值独立验证目标 `≤3 mV`，硬底线 `≤5 mV` |
| 频率 | 基频误差目标 `≤500 Hz`，硬底线 `≤1 kHz` |
| 数据 | 8192 点/帧、12 包；CRC/序号/frame_id/OTR/FIFO/drop/NIC/GEM 错误全零 |
| 响应 | 首个有效帧 `≤250 ms`；完整系统最终预算 `≤2 s` |
| 长稳 | 10,001 帧零数据/协议错误，500 秒增益漂移 `≤0.05 dB` |

若 DG、RTM、探头综合不确定度大于 3 mV，只能判断 5 mV 底线或报告测量上限，不输出
虚假的小数位。孤立离群点可在稳健拟合中降权，但原始帧、位置和未修复指标必须保留。

## 9. 执行顺序与停点

1. **M11-0**：离线生成全部正弦/ARB、理论谱线/Vpp/RMS、1～10 MHz折叠表、WaveBench
   plans 和 manifest；完成私有 0.5 Vpp安全配置、双高阻/双通道同窗 runner、DP832
   零写门禁、dry-run、单元测试、计划检查和 SHA-256。已于 2026-07-31 完成。
2. **M11-1**：完成 A/B/C；探头、输入语义、供电、噪声、自激或三级增益未查清前，
   不进入大信号。需要移动 CH2 到 AD8065 输出引脚时，由现场明确完成并复核接线。
3. **M11-2**：D已完成至450 mVpp；500 mV余量点按上述实测停止线封存，不在其他
   频率重试。随后完成 E，冻结第一版端到端校准，只有保留点通过后才进入多音。
4. **M11-3**：完成 F/G/H；先证明 1～3 MHz FIR 和赛题等效矩阵，再进入正式上限。
5. **M11-4**：完成 I 的 4～10 MHz 正式单频覆盖以及 5/10 MHz B-edge组合；这些点
   不得因“最高谐波 3 MHz”被误删，限制只针对多音波形。
6. **M11-5**：A～I 全部通过后执行 J 响应、最低供电点复测和 10,001 帧长稳；最后
   恢复正式 real-ADC 镜像和 DG 安全 OFF 状态，DP832 只读复核。
7. `>10 MHz` 折叠实验仅在单独授权、独立安全计划和独立报告中执行，不阻塞 M11 收口。

## 10. 证据目录与记录字段

正式证据保存到：

```text
tool-of-rei/evidence/m11-real-frontend-<date>/
```

至少包含：

- `README.md`：范围、接线、结论和未覆盖项；
- `preflight/`：仪器 ID、双探头/通道比对、DG/RTM负载、DP832只读状态、供电和温度；
- `points/<case>/rtm/`：同次 acquisition 的 CH1/CH2 原始证据；
- `points/<case>/lan/`：完整帧、LAN 报告和时间窗；
- `points/<case>/analysis.json`：Ksrc/Gfb/Kmatch/Gamp/Kadc/Ke2e、误差、不确定度和 PASS/FAIL；
- `arb/`：谱线、相位、crest factor、payload 和哈希；
- `calibration/`：训练点、保留点、校准表和 `calibration_id`；
- `formal-10mhz/`：4～10 MHz正式单频点及5/10 MHz组合点；
- `alias/`：仅在另行授权后保存 `>10 MHz` 实验性折叠频率、仪器带宽限制和残余上界；
- `longrun/`：10,001 帧、pcap、温度/电流/增益漂移；
- `SHA256SUMS` 与机器可读总 manifest。

只有 DG 设置、CH1、CH2、FPGA 原始帧、刺激时间窗和负载状态证据齐全，测试点才可进入
正式校准或设计报告。WaveBench 原生 run/raw 必须完整复制并逐树核对，不能只摘截图。

每点机器可读记录至少包含 `case_id`、DG函数/负载/offset/Vpp/谱线及ON-OFF时间、
RTM两通道探头倍率/耦合/带宽/采样率、Vin/Vadc的DC/Vpp/RMS/THD/谱线、
`Ksrc/Gfb/Kmatch/Gamp/Kadc/Ke2e`、FPGA sample rate/帧状态、`calibration_id`、
原始证据路径、SHA-256、不确定度、PASS/FAIL和失败原因。
