## 冻结架构

```text
AD9226 通道 A，65 MSPS
  → 码型归一化、三级 FIR、16 倍抽取
  → 4.0625 MS/s、8192 点 S16、50 ms 投递
  → PL 双 bank / AXI-Stream / Simple S2MM DMA
  → Zynq PS / CSLP v0.1 / UDP
  → ESP32-P4 为唯一控制端；电脑镜像仅为可选被动诊断
```

比赛数据路径只认 `PL → DMA → PS → CSLP/UDP`。tag 中的 SPI 诊断实现是历史代码，不能作为比赛接口、默认验收入口或 LAN 故障旁路。
