# 已知问题

## 高风险
- 问题：LAN 接收层与显示/频谱管线均已独立验证，但尚未连接成真实采集—传输—FFT—显示闭环。
  - 影响：组合固件仍是 CSLP receiver 运行、LiveDataPipeline 消费模拟 producer；不能代表真实测量精度与时延。
  - 规避：只保留一个正式 mailbox consumer，按 `FrameCursor` acquire/release，并把真实 8192 点 FFT 接到既有 4097 Bin A/B 接口。
  - 状态：合并完成，业务接线待实现。

- 问题：AD9226 MODE/DFS 码型、模拟极性和 OTR 接线尚未由原理图/实测冻结。
  - 影响：可能造成符号、零点、一 LSB 偏差或无法识别超量程，影响 5 mV 精度。
  - 规避：用直流、斜坡、正弦验证 straight binary/补码与极性，并让 OTR 与数据流水线对齐。
  - 状态：待硬件确认。

## 中低风险
- 问题：FPGA `.2` 离线时，CSLP receiver 约每秒重新握手并产生多条 `send errno=12`/timeout 日志。
  - 影响：不影响 LVGL/模拟分析继续运行，但日志偏密，可能掩盖其他告警并产生不必要的重试开销。
  - 规避：真实联调时让 `.2` 正常回应；后续为离线重连增加指数退避与日志限流，并保留在线后的快速恢复。
  - 状态：组合上板已复现；UI 健康统计无丢帧，待优化重连策略。

- 问题：M5 启动时直接 DFT 曾使首个有效界面约 2.7 秒，未满足 2 秒目标。
  - 影响：不能宣称整机启动时限通过。
  - 规避：把重计算移到首帧后，或在真实链路改用高效 FFT。
  - 状态：待 LVGL-M7。

- 问题：TIME 页 1P/3P 切换重绘约 640 列 min/max，历史上出现一次 342 ms UI 间隔。
  - 影响：交互切换时存在一次可预期的较长重绘。
  - 规避：后续可改用画布或分块缓存；正常动态管线最大间隔已降至 58 ms。
  - 状态：功能正确，待性能收口。

- 问题：MIPI-DSI 初始化报告 `on_frame_buf_complete unavailable`。
  - 影响：buffer-switch release/dummy-draw 路径可能不可用。
  - 规避：继续使用已验证的普通刷新路径，并做最终 30 分钟稳定性测试。
  - 状态：10 分钟与短时压力已通过，待 M7。

- 问题：`esp_codec_dev` 1.5.11 发布包有 CMake 语法错误。
  - 影响：解除依赖锁或升级时可能重新构建失败。
  - 规避：`idf_component.yml` 精确锁定 1.5.10，升级前单独验证。
  - 状态：当前锁定有效。

- 问题：外部协议文档仍用 `acquire_latest(after_frame_id)` 简写，未体现 session-aware `FrameCursor`。
  - 影响：调用者照抄可能在 FPGA 重启后忽略低 frame_id 新 session。
  - 规避：后续更新外部文档；当前以源码 API 和本快照为准。
  - 状态：wire format 不受影响。

- 问题：DISABLE_PUSH、固定正弦向量、直连冷启动和启动失败逐资源故障注入尚未完成。
  - 影响：控制关闭、分析输入、2 秒时限和异常启动覆盖仍不完整。
  - 规避：按任务清单逐项补测，不外推现有 PASS。
  - 状态：Backlog/Next。

- 问题：电脑 `.5` 为临时地址，CP2102N 曾出现 `-71 (EPROTO)` 和过流计数。
  - 影响：网卡重连可能丢 `.5`，USB 电气问题可能中断烧录或日志。
  - 规避：不碰 `.4`；需要时恢复 `.5`。USB 再报错先检查供电、线材和端口。
  - 状态：最近一轮网络与串口正常。
