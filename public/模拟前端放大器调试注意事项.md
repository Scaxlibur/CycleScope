# CycleScope 模拟前端放大器调试注意事项

> 当前状态：本文保留前端理论、调试接法和历史压力计划。最终标定已将普通输入范围冻结为不超过 250 mVpp；450 mVpp 压缩点作为历史负证据保留，不再参与拟合、holdout 或验收。当前量化结论请看 [测试与证据索引](测试与证据索引.md)。

本文用于记录 G 题模拟前端放大器、50 Ω 接口、AD9226 负载、频响与失真的统一调试口径。任何更换模块、反馈电阻、输出串联电阻、滤波器或供电方案的操作，都应按本文重新验收。

协议和数字链要求以 [CSLP-G题采样与处理-Profile-v0.1](CSLP-G题采样与处理-Profile-v0.1.md) 为准；本文不修改协议字段定义。

## 1. 当前候选前端事实

截至 2026-07-31，当前前端已更换为：

- 运放：`AD8065`，沿用同相放大结构。
- 增益电阻：`RF = 1.608 kΩ`、`RG = 200.2 Ω`；反馈网络理想增益
  `1 + RF/RG = 9.031968032 V/V`。
- 输出采用约 50 Ω串联匹配并驱动 AD9226 的真实 50 Ω输入负载；若两者均精确为 50 Ω，ADC 节点理论加载增益为 `4.515984016 V/V`。
- 该 4.516 倍公式假设 `RF` 在输出串联电阻之前、直接从 AD8065 输出引脚取样；反馈若取自负载侧，必须重新建模。
- 当前“约 4 倍”只是从示波器画面得到的粗略估算，不是正式加载增益测量，不得写入校准参数。
- 计划供电仍为 `+5 V / 0 V / -5 V`，正式证据须由装置单路 5 V输入经内部变换产生。
- LMH6609 方案此前的 500 mVpp、3 MHz、噪声和失真观察不能继承给 AD8065，必须全部重测。

AD8065 可以作为新候选，但最终冻结仍需定量完成匹配网络分压、增益压缩、THD、互调、噪声、温升和端到端校准。

## 2. 赛题边界与增益余量

| 项目 | 边界 |
|---|---:|
| `u_a` 整体峰峰值 | 100～250 mVpp |
| `u_b` 整体峰峰值 | 50～250 mVpp |
| 干扰 `u_J` | 200 mVpp，`f_J >= 1 MHz` |
| 第三项理论最坏输入 | `250 + 200 = 450 mVpp` |
| 单个基波/谐波最小幅值 | 5 mVpeak |
| 有效测量频带 | 10～500 kHz |

按 AD9226 模块标称 `10 Vpp / 4096 code` 和精确 50 Ω匹配理论增益估算：

```text
ADC 标称 LSB                 = 2.44140625 mV/code
反馈网络理想增益             = 9.031968032 V/V
50 Ω理论加载增益             = 4.515984016 V/V
输入端等效 LSB              = 2.44140625 / 4.515984016
                             = 0.540614458 mV/code
50 mVpp 最小整体信号码程    ≈ 92.49 code p-p
5 mVpeak 最小谱线码程        ≈ 9.25 code peak
450 mVpp 最坏 ADC 输入       ≈ 2.03219 Vpp
500 mVpp 验证点 ADC 输入     ≈ 2.25799 Vpp
```

若以后定量测得加载增益确实约为 4，输入端等效比例约为 `0.610351562 mV/code`，最小 5 mVpeak 谱线仍约为 8.19 code peak。两种估算均有足够量化余量，也不会逼近 AD9226 的 10 Vpp 标称满量程，但正式 `scale_uV_per_lsb` 必须等待端到端测量。

[ADI AD8065/AD8066 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/AD8065_8066.pdf)建议反馈电阻为 300 Ω～1 kΩ。当前 `RF = 1.608 kΩ` 超出建议范围，必须关注峰化、振铃、噪声和相位。数据手册的一阶模型在当前噪声增益下给出约 7.20 MHz 闭环带宽，因此 500 kHz 有效带应有余量，但 4～10 MHz 可能已有明显模拟滚降；这部分不能错误归因给 FPGA FIR。

## 3. 标准测量接线

推荐使用下列接法测量加载增益：

```text
信号发生器 CH1（50 Ω输出模式） ──┬── 放大器 IN
                                   └── 示波器 CH1（高阻，测实际 Vin）

AD8065 OUT ── 输出串联匹配电阻 ─────── 示波器 CH2（50 Ω，模拟 AD9226 负载）
```

注意：

- 增益必须用示波器实测的 `Vout / Vin` 计算，不要直接拿信号发生器面板值相除。
- CH2 设为 50 Ω时，不得再并接 AD9226，否则两个 50 Ω并联成为 25 Ω。
- 若 AD9226 已连接，示波器只能用高阻探头并接在 ADC 输入端。
- 10 倍高阻探头应使用短接地弹簧，禁止用长鳄鱼夹测高速放大器输出。
- 信号源面板幅值、实际 BNC 电压、AD8065 输出引脚电压和 ADC 负载端电压是四个不同概念，记录时必须注明测量节点。
- RTM2032 只有两个通道；冻结匹配分压时保持 CH1 测 Vin，CH2 先后测 AD8065 输出引脚和 ADC 节点。两次刺激的 CH1 幅值必须一致，顺序测量不得冒充三节点同窗相位结果。

### 输出串联电阻造成的二分之一增益

若放大器输出端存在约 50 Ω串联电阻，再连接 50 Ω负载，则负载端电压为：

```text
Vload / Vopamp = 50 / (50 + 50) ≈ 0.5
```

当前反馈网络理论为 9.032 倍，精确 50 Ω串联匹配后的 ADC 节点理论为 4.516 倍。遇到目测约 4 倍时，应分别定量测 AD8065 输出引脚和 ADC 节点，确认实际串联电阻、负载与探头修正；不能直接把目测结果当成 4.000 倍。

## 4. 调试顺序

### 4.1 断电检查

1. 拔掉信号源、示波器和 ADC，关闭正负电源。
2. 测量 BNC 中心到模拟地的直流电阻并记录；目标应接近设计值 50 Ω。
3. 确认输出串联电阻的实际阻值，不能只看丝印猜测。
4. 检查 `VCC-GND`、`VEE-GND` 和 `VCC-VEE` 无异常短路。
5. 确认输入、输出和反馈网络没有被焊锡桥或原铜箔旁路。

### 4.2 空载直流与自激检查

1. 输入关闭或用 50 Ω接地，供电设为 `±5 V`。
2. 在芯片电源脚附近核对正负电压，而不是只读电源面板。
3. 测量输出直流偏置；若达到数百毫伏，应停止幅度测试并排查。
4. 示波器使用最高可用带宽观察输出；输入关闭时不得存在持续高频振荡。
5. 记录静态电流和热机后的器件温度；快速升温或电流异常通常意味着自激、接反或输出短路。

### 4.3 小信号加载增益

1. CH2 使用真实 50 Ω负载。
2. 输入 `100 kHz / 50 mVpp` 正弦。
3. 同时测量实际 `Vin`、实际 `Vout` 和输出直流偏置。
4. 计算加载增益 `G0 = Vout / Vin`，作为后续增益压缩基准。
5. 分别计算运放引脚增益 `Gfb`、匹配分压 `Kmatch` 和 ADC 节点加载增益 `Gamp`；理论值依次约为 9.032、0.5 和 4.516，最终以定量实测为准。

### 4.4 幅度与线性

在 `10 kHz`、`100 kHz`、`500 kHz` 至少三个频率，依次测试：

```text
50 / 100 / 250 / 450 / 500 mVpp
```

每个点记录 `Vin`、`Vout`、加载增益、直流偏置、THD、二次/三次谐波和波形截图。工程目标：

- 450 mVpp 与 500 mVpp 时无削顶、无明显过冲和恢复异常。
- 相对小信号基准 `G0`，增益压缩目标不超过 `0.5%`，验收不得超过 `1%`。
- 单音 THD 目标优于 `-60 dBc`；仪器底噪不足以证明时，应记录测量下限。
- 在最低预期电源电压和热机状态下重复 500 mVpp 点，防止室温瞬时结果掩盖余量不足。

### 4.5 频率响应

有效带扫描至少覆盖 `10～500 kHz`，建议继续记录至 `3 MHz`。保存每个频点的实际复数响应或至少幅值、相位和测试幅度。

`3 MHz` 内平坦只能证明有效带裕量，不能证明具备抗混叠能力。本轮正式实物测量扩展至 `5 / 7.2 / 7.5 / 10 MHz`，其中 7.2 MHz 用于观察当前噪声增益模型预测的闭环截止附近；10 MHz 以上（优先 65 MHz 整数倍附近）作为实验性测量，或结合独立模拟低通给出衰减依据。主办方没有规定干扰最高频率，因此“正式测到 10 MHz”不能写成已经全面覆盖。FPGA数字滤波无法消除进入ADC之前已经混叠到0～500 kHz的能量。

### 4.6 干扰与互调

单音500 mVpp通过不能代替第三项组合输入测试。至少测试：

```text
u_b：整体 250 mVpp，频率成分覆盖至 500 kHz
u_J：200 mVpp，先测 1 MHz，再增加更高频率
```

检查放大器输出不削顶，并观察10～500 kHz内是否出现输入中不存在的互调谱线。任何落入有效带的模拟互调都不能靠后续波特图校准或数字低通可靠区分。

## 5. 噪声测量

1. 输入使用与正式系统相同的50 Ω端接，禁止悬空测噪声。
2. 输出连接真实50 Ω负载。
3. 分别记录时域 RMS、峰峰值和0～500 kHz频谱中的最大离散杂散。
4. 将输出噪声除以实测加载增益，得到输入端等效噪声。
5. 工程目标为输入端等效 RMS 噪声不超过 `0.5 mVrms`，有效带内固定杂散尽量低于 `1 mVpeak`；最终以整机5 mV误差预算验证为准。

“看起来噪声不大”只能用于初筛，不能写入正式测试报告作为数值结论。

## 6. AD9226与整机校准

按精确 50 Ω匹配理论值计算的名义换算为 `540.614458 µV/input-code`；若加载增益最终约为 4，则约为 `610.351562 µV/input-code`。旧 LMH6609 的 481/488 µV/LSB 均已失效，必须通过端到端实测替换：

```text
BNC → 放大器/模拟滤波 → AD9226 → FPGA FIR/抽取 → P4测量
```

校准要求：

- 至少完成零偏和两个幅度点，正式建议覆盖50、250、450 mVpp。
- 扫描10～500 kHz并记录增益与相位；频率校正只应用于有效测量带。
- 每次更换放大模块、电阻、滤波器、ADC通道或负载方式，都必须更新 `calibration_id`。
- 不得逆补偿1 MHz以上阻带，否则会把本应抑制的干扰重新放大。
- 评分基准原则上是信号发生器50 Ω模式的设置值；输入阻抗偏离50 Ω造成的幅值差也必须包含在端到端校准中。

## 7. OTR排查顺序

在精确 50 Ω匹配理论增益和不超过500 mVpp输入下，ADC端约为2.258 Vpp。若仍出现 OTR：

1. 用示波器在AD9226输入端确认真实Vpp和直流偏置。
2. 断电核对 `ORA` 到FPGA管脚的连通性、是否短接到数据位或电源。
3. 检查ORA极性、同步和帧状态锁存逻辑。
4. 使用已知低幅度输入验证OTR能否清零。
5. OTR未清零前，不得使用该帧进行增益、频响、位序或精度标定。
