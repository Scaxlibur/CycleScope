# CycleScope 前端增益与逐频补偿指南

## 1. 状态、范围与结论

- 状态：当前硬件、标量校准和 P4 逐频补偿事实说明；已随本次 P4 源码接入。
- 适用范围：BNC 输入、AD8065 模拟前端、AD9226、FPGA FIR/抽取、Zynq PS CSLP 封包和 ESP32-P4 测量显示。
- 配套文档：[模拟前端放大器调试注意事项](../模拟前端放大器调试注意事项.md)、[信号前端测量方案](./信号前端测量方案.md)、[CSLP G题采样与处理 Profile v0.1](../CSLP-G题采样与处理-Profile-v0.1.md)、[CSLP UDP 通信协议 v0.1](../CSLP-UDP-通信协议-v0.1.md)、[验收证据索引](../../docs/验收证据索引.md)。

先把三件不同的事分清：

1. **实际模拟放大**发生在 AD8065 前端；它不是 FPGA 或 P4 算出来的。
2. **每帧标量换算**来自 CSLP 的 `scale_uV_per_lsb=516`、`offset_uV=-6761` 和 `calibration_id=25030`。
3. **10～500 kHz 逐频幅值补偿**现在已在 P4 运行；它使用冻结的 `C5DCDE41` 资产，而不是直接读取或在线传输 CSV。

P4 的运行时资产只在上游身份完全匹配时启用：

```text
calibration_id=25030
scale_uV_per_lsb=516
offset_uV=-6761
filter_profile=1
sample_rate_hz=4,062,500
frame_sample_count=8,192
```

身份不匹配、频率在 10～500 kHz 外或资产非法时，链路必须拒绝该补偿，而不是外推或偷偷套用旧表。

## 2. 全链路中各层的职责

```text
BNC 输入电压 uIN
    ↓  AD8065 + 输出匹配网络：物理放大/分压
AD9226 输入电压 uADC
    ↓  ADC：量化为有符号码值 code
FPGA：码型/极性归一化 → FIR低通 → /16抽取
    ↓  保持码值尺度，不按模拟前端增益作电压换算
Zynq PS：把比例、偏置、校准身份写入每帧 CSLP WAVE 元数据
    ↓  scale_uV_per_lsb / offset_uV / calibration_id
ESP32-P4：标量码值换算 → FFT/候选峰 → 频率精修/正弦投影
    ↓  按 C5DCDE41 对带内谱线、RMS、Vpp 和显示频谱作逐频幅值校正
显示：谱线幅值、RMS、Vpp 和频谱图
```

FPGA FIR 的职责是抗混叠、抑制干扰并保持已定义的数字增益；它不承担模拟前端的幅值校正。Zynq 只传递标量身份，不新增 CSLP 线上频响字段。

## 3. AD8065 模拟前端增益

### 3.1 理论计算

当前前端按同相放大结构记录的名义电阻为：

```text
RF = 1.608 kΩ
RG = 200.2 Ω
```

若反馈取样位于输出串联匹配电阻之前，运放输出引脚的理论反馈增益为：

```text
Gfb = 1 + RF / RG
    = 1 + 1608 / 200.2
    = 9.031968032 V/V
```

若运放输出串联电阻 `RS≈50 Ω`，AD9226 输入等效负载 `RL≈50 Ω`，匹配网络分压为：

```text
Kmatch = RL / (RS + RL)
       = 50 / (50 + 50)
       = 0.5

Gamp = Gfb × Kmatch
     = 4.515984016 V/V
```

理想条件下：

```text
uADC ≈ 4.515984016 × uIN
```

### 3.2 三种数值不能混用

| 数值 | 用途 | 能否直接写入校准 |
|---|---|---|
| `Gfb = 9.032` | 运放反馈网络理论增益 | 否；仅用于拓扑与余量核算 |
| `Gamp = 4.516` | 精确50 Ω假设下的 ADC 节点理论加载增益 | 否；仅用于理论量程核算 |
| 示波器粗估“约4倍” | 初步上板观察 | 否；不能当硬件常数 |
| BNC端到端标定和频响资产 | 真实测量、显示与误差预算 | 是；必须绑定身份和证据 |

若 `RF` 实际从匹配电阻之后的 ADC 节点反馈，以上“乘 0.5”模型不成立，必须按实际原理图重算。理论值和示波器读数都不能替代端到端校准。

## 4. ADC 码值与标量校准

### 4.1 名义码值换算

按 AD9226 模块标称 `10 Vpp / 4096 code`：

```text
ADC端名义LSB = 10 V / 4096
             = 2.44140625 mV/code
```

按理论加载增益折回 BNC 输入端：

```text
输入端名义LSB = 2.44140625 / 4.515984016
               = 0.540614458 mV/code
               = 540.614458 µV/code
```

这是量程预算的理论值，不是比赛显示比例。

### 4.2 当前上游标量身份

| 字段 | 当前值 | 语义 |
|---|---:|---|
| `calibration_id` | 25030 | 当前帧的非零标量校准身份；正式帧置 `CALIBRATED` |
| `scale_uV_per_lsb` | 516 | 标量码值→BNC输入端换算比例 |
| `offset_uV` | -6761 | 同一模型下的输入端零偏 |
| `filter_profile` | 1 | `G_BAND_500K_DECIM16` |
| 抽取后采样率 | 4,062,500 sample/s | 65 MSPS 经 `/16` |
| 已验证帧长 | 8192 | 当前 P4 频响资产只绑定此帧长 |

每帧的标量公式为：

```text
u_input_uV = code × scale_uV_per_lsb + offset_uV
           = code × 516 - 6761
```

P4 会去直流，因此常量偏置通常从纯交流幅值中抵消；它仍是波形直流语义和身份核对的一部分。

## 5. 当前在线实现

### 5.1 FPGA、Zynq 与 P4 的分工

1. FPGA 完成码型/极性归一化、FIR 低通和16倍抽取，不根据 AD8065 理论增益改写样点比例。
2. Zynq PS 在 WAVE_DATA 元数据中写入 `scale_uV_per_lsb`、`offset_uV` 和 `calibration_id`。
3. P4 在 FFT 前按标量换算为伏特、去直流、计算正频谱、选峰、精修频率并执行 `project_at_frequency()`。
4. P4 随后对已确认的带内分量执行分段线性插值校正；校正值写入谱线、RMS、Vpp 和带内显示频谱。
5. 候选峰检测、排序和阈值仍基于未逐频校正的标量频谱，避免校准表的小幅起伏改变检出策略。

实现对应：

- `ESP32-P4/main/app/frequency_response_compensation.hpp`：资产合法性、六字段身份匹配、带内插值和因子计算；
- `ESP32-P4/main/app/frequency_response_profile_generated.hpp`：不可手工编辑的 12 锚点资产；
- `ESP32-P4/main/app/fft_processor.cpp`：投影后分量、RMS/Vpp、带内 bin 的实际校正；
- `main.cpp`：将生成资产显式传入正式 pipeline。

## 7. 校正位置、范围与相位边界

### 7.1 为什么不在时域逐点乘法

一个时域样点同时含基波、谐波、噪声和带外残余，不能根据“这个样点属于哪个频率”选择系数。要在时域完成频响均衡必须另行设计、量化并验证数字均衡器；它会改变噪声、FIR 阻带和相位。

本工程采用的分量级实现顺序是：

```text
码值 → 516 µV/code 标量换算 → 去直流 → FFT
→ 候选峰/谐波族 → 基频精修 → project_at_frequency()
→ 对每条确认分量查表并乘 K(f)
→ 计算/重构 RMS、Vpp，发布谱线和显示频谱
```

### 7.2 插值与带外规则

1. 只接受 `10,000 Hz ≤ f ≤ 500,000 Hz`。
2. 命中锚点时直接取锚点值。
3. 锚点之间对 `input_uv_per_code` 按频率分段线性插值。
4. 区间外不外推；低于10 kHz或高于500 kHz的分量不使用 `C5DCDE41` 补偿。
5. 1 MHz 以上的阻带、干扰残余和混叠诊断分量绝不逆补偿。
6. 校正后的幅值驱动正式谱线、`true_rms_volts`、谐波重构 Vpp 和带内显示 bin；无已确认分量时的时域兜底 RMS/Vpp 不伪装为逐频校正结果。

### 7.3 相位列的边界

历史 `response.csv` 中的 `analog_ch2_minus_ch1_phase_deg` 只代表模拟前端 CH2 相对 CH1 的同次响应。DG4202 和 FPGA 没有共同触发，因此它不能作为全链路绝对相位补偿，也不能据此宣称完整波形去嵌入。本资产只校正幅值，不校正相位。

## 8. 校准绑定与变更纪律

逐频表必须同下列条件原子绑定：

- `calibration_id`、前端版本、反馈/匹配电阻和负载拓扑；
- AD9226 通道、码型、输入范围和偏置；
- FPGA bitstream、`filter_profile`、抽取后采样率和帧长；
- 信号源 50 Ω 设置与 BNC 输入基准；
- `response.csv`、不确定度/holdout报告、生成资产和 SHA-256。

当前资产只绑定 `8192点 / 4.0625 MS/s / filter_profile=1`。16384 或32768点模式没有经过独立复验和新身份分配时，不能沿用 `25030` 或 `C5DCDE41`。

每次更换前端、ADC通道、负载、数字滤波、采样率、帧长或校准基准，都必须重新采集训练/独立 holdout，生成新表、分配新身份、重新生成 P4 资产，并完成谱线/RMS/Vpp/带外拒绝验证。

## 10. 不要做的事

- 不要把理论 `4.516`、示波器粗估“约4倍”、标量 `516 µV/code` 和 `K(f)` 当成同一个量。
- 不要在 FPGA 中为了“补偿增益”任意放大 FIR 后码值，破坏量程、溢出和校准语义。
- 不要把 CSLP 的 `CALIBRATED` 标志单独理解为“P4已经逐频补偿”；P4 补偿还要求 `C5DCDE41` 资产和完整上游身份。
- 不要对 1 MHz 以上干扰、阻带残余或未知混叠做逆补偿。
- 不要在未重新验证的 16384/32768 模式沿用 8192 的 `25030/C5DCDE41` 资产。
